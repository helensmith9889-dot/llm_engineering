# Python 基础语法 — 导入（import）

> 来源：`week1/day1_zh.ipynb` 第一段代码

## 这段代码在干什么？

程序要用别人写好的功能，就得先 **导入（import）**。  
下面五行不是在「做事」，而是在 **把工具箱搬进来**，后面的单元格才能用这些名字。

```python
import os
from dotenv import load_dotenv
from scraper import fetch_website_contents
from IPython.display import Markdown, display
from openai import OpenAI
```

---

## 两种导入写法

| 写法 | 含义 | 用时怎么写 |
|------|------|------------|
| `import 模块` | 导入整个模块 | `模块.名字`，如 `os.getenv(...)` |
| `from 模块 import 名字` | 只拿模块里的某个东西 | 直接写 `名字`，如 `load_dotenv()` |

---

## 逐行说明

### 1. `import os`

- **是什么**：Python **标准库**（装 Python 就自带，不用 pip）
- **干什么**：和操作系统打交道——读文件路径、环境变量等
- **本课用途**：读环境变量，例如 `os.getenv("OPENAI_API_KEY")`，拿到 API 密钥

### 2. `from dotenv import load_dotenv`

- **是什么**：第三方库 `python-dotenv`（需要 `pip install`）
- **干什么**：把项目里的 `.env` 文件内容加载进环境变量
- **为什么**：密钥不要写进代码 / 笔记本；写在 `.env`，用 `load_dotenv()` 读进来

```python
load_dotenv()  # 执行后，os.getenv("OPENAI_API_KEY") 才能读到 .env 里的值
```

### 3. `from scraper import fetch_website_contents`

- **是什么**：本课程自己写的模块 `scraper.py`（同目录/项目内）
- **干什么**：抓取网页正文（或相关内容）
- **本课用途**：给「网页摘要浏览器」喂原始网页文字

```python
text = fetch_website_contents("https://example.com")
```

### 4. `from IPython.display import Markdown, display`

#### IPython 是什么？

**IPython** = **Interactive Python**，一种增强版的交互式 Python 环境。

普通 Python 在终端里敲代码、看结果；IPython 在此基础上加强了：

- 更好的补全、历史、帮助（如 `?`）
- 富文本输出（Markdown、图片、HTML）
- Jupyter Notebook 的「内核」就是基于 IPython

所以这不是另一种编程语言，而是「跑在 Jupyter 里的那个增强 Python」。  
`IPython.display` 是它提供的 **展示模块**。

#### `Markdown` 和 `display` 分别做什么？

| 名字 | 作用 |
|------|------|
| `Markdown(字符串)` | 把字符串「标记成 Markdown」（标题、加粗、列表等），本身还不显示 |
| `display(对象)` | 把东西真正画到当前单元格的输出区 |

本课常见写法（见 day1 里显示摘要）：

```python
display(Markdown(summary))
```

对比：

- `print(summary)` → 纯文本；`## 标题` 不会变成大标题
- `display(Markdown(summary))` → 按 Markdown 格式漂亮渲染

```python
display(Markdown("## 这是标题"))
```

### 5. `from openai import OpenAI`

- **是什么**：官方 `openai` Python SDK（软件开发工具包）里的客户端类
- **干什么**：调用 OpenAI 的 Chat Completions 等 API
- **本课用途**：把网页文字发给大模型，拿到摘要

```python
openai = OpenAI()  # 创建客户端；密钥通常来自环境变量 OPENAI_API_KEY
```

# Python 基础语法 — 函数定义（def）

> 来源：`week1/day1_zh.ipynb` 里的 `messages_for` / `summarize` / `display_summary`

## 这段代码在干什么？

前面单元格已经能「手动」拼消息、调 API。  
用 **`def` 定义函数**，就是把一段重复步骤 **打包成名字**，以后写一行调用即可，不用复制粘贴整段代码。

```python
def messages_for(website):
    return [
        {"role": "system", "content": system_prompt},
        {"role": "user", "content": "必须使用中文输出" + user_prompt_prefix + website}
    ]

def summarize(url):
    website = fetch_website_contents(url)
    response = openai.chat.completions.create(
        model="qwen3:8b",
        messages=messages_for(website)
    )
    return response.choices[0].message.content

def display_summary(url):
    summary = summarize(url)
    display(Markdown(summary))
```

---

## `def` 长什么样？

```python
def 函数名(参数1, 参数2, ...):
    # 缩进的代码 = 函数体（被调用时才执行）
    return 结果   # 可选：把值交还给调用方
```

| 零件 | 含义 |
|------|------|
| `def` | define：我要定义一个函数 |
| 函数名 | 以后调用时用的名字，如 `summarize` |
| `(参数)` | 调用时从外面「传进来」的数据，如 `url` |
| `:` + 缩进 | 下面缩进的几行都属于这个函数 |
| `return` | 把结果送出去；没有 `return` 时默认返回 `None` |

关键对比：

- **定义** `def summarize(url): ...` → 只是「写好说明书」，**还不会跑**抓网页 / 调 API
- **调用** `summarize("https://edwarddonner.com")` → 这时才真正执行函数体

---

## 逐个函数说明

### 1. `messages_for(website)`

- **输入**：网页正文（字符串）`website`
- **输出**：OpenAI 要的 messages 列表（system + user）
- **作用**：把「拼消息」这件事固定下来，避免每次手写那两行字典

```python
messages_for(ed)  # 返回 [{"role":"system",...}, {"role":"user",...}]
```

### 2. `summarize(url)`

- **输入**：网址 `url`
- **输出**：大模型生成的摘要字符串
- **内部步骤**：
  1. `fetch_website_contents(url)` → 抓正文
  2. `messages_for(website)` → 拼 messages
  3. `openai.chat.completions.create(...)` → 调模型
  4. `return` 回复文本

```python
summarize("https://edwarddonner.com")  # 得到一段 Markdown 摘要字符串
```

### 3. `display_summary(url)`

- **输入**：网址 `url`
- **输出**：主要靠副作用——在笔记本里 **显示**；函数本身不一定有人用它的返回值
- **内部步骤**：先 `summarize(url)`，再 `display(Markdown(summary))`

```python
display_summary("https://edwarddonner.com")  # 单元格输出区漂亮渲染
```

---

## 一张图串起来（三个函数怎么叠）

```
URL
 │
 ▼
display_summary(url)
 │
 ├──► summarize(url)
 │       ├──► fetch_website_contents(url)  → 网页正文
 │       ├──► messages_for(正文)           → messages 列表
 │       └──► OpenAI API                   → 摘要字符串
 │
 └──► display(Markdown(摘要))             → 笔记本里显示
```

上层函数 **调用** 下层函数：这就是「组合」——小功能叠成大功能。

---

## 参数 vs 实参（容易混）

| 说法 | 出现在哪 | 例子 |
|------|----------|------|
| **参数（形参）** | 定义时括号里的名字 | `def summarize(url):` 里的 `url` |
| **实参** | 调用时真正传入的值 | `summarize("https://...")` 里的网址字符串 |

函数体里写的 `url`，运行时就是你传入的那个字符串。

---

## `return` 和「只做事不返回」

| 写法 | 调用方拿到什么 | day1 例子 |
|------|----------------|-----------|
| `return 某个值` | 那个值，可以赋给变量或再传给别人 | `summarize` → 摘要字符串 |
| 没有 `return`（或只 `display`） | `None`；重点在屏幕上看到效果 | `display_summary` 主要在展示 |

```python
text = summarize(url)           # text 里有摘要
display_summary(url)            # 好看地显示；一般不再接返回值
```

# Python 基础语法 — 列表推导式与字典取值

> 来源：`week2/day3_zh.ipynb` 里整理聊天历史的那一行  
> Gradio 聊天回调整体见：[`Gradio.md`](Gradio.md)（「ChatInterface」一节）

## 这行代码在干什么？

```python
history = [{"role": h["role"], "content": h["content"]} for h in history]
```

对 `history` 列表里的**每一条消息**，只取出 `role` 和 `content`，做成新字典，再组成新列表。

---

## `h` 是什么？

`h` 是 **循环变量的名字**，表示列表里的 **当前这一项**（history item）。

读成：

> 对 `history` 里的每一条 `h`，用 `h["role"]`、`h["content"]` 做一个新字典。

等价于手写循环：

```python
new_history = []
for h in history:          # h = 当前这一条消息字典
    new_history.append({
        "role": h["role"],
        "content": h["content"]
    })
history = new_history
```

名字可以改成 `msg`、`item`；短名 `h` 只是习惯写法。

---

## 列表推导式长什么样？

```python
[ 表达式 for 变量 in 可迭代对象 ]
```

| 零件 | 本例 |
|------|------|
| 可迭代对象 | `history`（消息列表） |
| 变量 | `h`（每一条） |
| 表达式 | `{"role": h["role"], "content": h["content"]}`（新字典） |

作用：用一行写出「遍历 + 变换 + 收集成新列表」。

---

## `h["role"]`：从字典取值

假设：

```python
h = {"role": "user", "content": "你好", "metadata": {...}}
```

| 写法 | 含义 |
|------|------|
| `h["role"]` | 用键 `"role"` 取值 → `"user"` |
| `h["content"]` | 用键 `"content"` 取值 → `"你好"` |

这是字典的**方括号键访问**，不是 `h.role` 那种属性写法。  
若键不存在，会报 `KeyError`。
