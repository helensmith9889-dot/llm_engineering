# 综合测试数据生成器（第 3 周项目）

## 目标
构建一个小型系统，生成用于测试 REST API 的合成 JSON 数据集。生成器应该接受规范（最初是 OpenAPI 文档）并为端点生成实际的示例有效负载。

该项目还用于探索法学硕士、量化水平和提示方法之间的差异。

---

# 第 1 阶段 — 最小生成器

## 1. 输入
- 从 **OpenAPI 规范 (YAML/JSON)** 开始
- 摘录：
  - 端点
  - 请求机构
  - 响应模式

## 2. 模式提取
编写一个解析器来提取：
- 对象字段
- 类型
- 限制条件

模式输出示例：```
{
  "endpoint": "/users",
  "method": "POST",
  "fields": [
    {"name": "id", "type": "integer"},
    {"name": "email", "type": "string"},
    {"name": "createdAt", "type": "datetime"}
  ]
}
```## 3. 提示生成器
将提取的模式转换为提示模板。

示例：

“生成 10 个与此模式匹配的真实 JSON 对象...”

包括约束：
- 类型
- 格式化
- 可选关系

## 4. 模型执行
针对不同模型运行提示。

候选人示例：
- 骆驼3
- qwen 编码器
- 菲

实验：
- 量化与非量化
- 不同的采样设置

## 5. 输出
将生成的数据集另存为：```
/data
  users.json
  orders.json
  products.json
```---
