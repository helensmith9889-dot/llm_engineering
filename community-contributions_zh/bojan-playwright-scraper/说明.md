# 🧠 社区贡献：基于异步 Playwright 的 AI 爬虫

## 概述
本项目是一个完全异步、无头浏览器爬虫，基于 Playwright 与 OpenAI API 构建。  
它抓取并分析四个 AI 相关网站内容，输出结构化的 Markdown 摘要与 Jupyter Notebook。  
选用 Playwright 而非 Selenium，因其更快更高效，适合现代网页抓取。

**开发者：** lakovicb  
**IDE：** WingIDE Pro 10（通过 nest_asyncio 兼容 Jupyter）  
**Python 版本：** 3.12.9（Anaconda 下开发与测试）

---

## 📦 功能
- 🧭 模拟类人交互（鼠标移动、滚动）
- 🧠 使用 OpenAI API 做 GPT 分析
- 🧪 通过 nest_asyncio 可在 JupyterLab 内运行
- 📊 Prometheus 指标，便于观察爬取过程
- ⚡ 用 diskcache 做智能内容缓存
- 📝 生成结构化 Markdown 摘要与 Jupyter Notebook

---

## 🚀 如何运行

### 1. 安装依赖
在终端执行：
```bash
conda install python-dotenv prometheus_client diskcache nbformat
pip install playwright openai
playwright install
```
> 注意：建议使用 Python 3.12 以获得更好性能。

---

### 2. 设置环境变量
在项目相关目录创建 `.env`，写入：
```env
OPENAI_API_KEY=your_openai_key
```
（可选）按需配置代理/登录参数。

---

### 3. 运行爬虫
```bash
python playwright_ai_scraper.py
```

运行后将抓取目标站点并生成摘要 Notebook。

---

## 📁 项目结构
- `playwright_ai_scraper.py`：主爬虫逻辑
- `notebook_generator.py`：根据抓取结果生成 notebook
- `notebooks/`：输出的摘要 notebook
- `requirements.txt`：依赖列表
