# LLM 驱动的数据集合成器：LLaMA 3 + Gradio 演示

本交互式演示展示了一条由 Meta 的 LLaMA 3.1 8B-Instruct 模型驱动的合成数据集生成流水线（以 4-bit 量化模式运行）。用户可用自然语言描述所需数据集的结构与逻辑，模型会据此生成表格数据。

## ✨ 说明

现代 LLM 能够对结构化数据格式进行推理，并生成逼真、带约束的数据集。本演示结合 LLaMA 3.1 instruct 模型与提示工程，从纯自然语言描述生成高质量合成表格数据。

关键组件：
- 通过 Hugging Face Transformers 使用 **LLaMA 3.1 8B-Instruct**
- 使用 `bitsandbytes` 进行 **4-bit 量化加载**，节省显存
- 面向 schema + 取值约束的 **自定义提示框架**
- 使用 Gradio 构建的 **交互界面**，便于生成数据

## 🚀 功能

使用本工具可以：
- 通过描述列名、数据类型、取值逻辑与行数来生成合成数据集
- 按年龄、性别、匹配条件等施加约束（例如：“40 岁以上女性；40 岁以下男性”）
- 预览原始模型输出，或提取结构化 JSON/表格结果
- 在 Gradio UI 中交互浏览并复制生成的数据集

## 🛠️ 原理简述

- 模型提示模板包含 **系统消息** 与用户指令
- 解析输出以提取合法 JSON 对象
- 生成数据在 Gradio 界面中展示，并可下载为 CSV

## 📦 依赖

- Python（推荐 Colab）
- `transformers`、`bitsandbytes`、`accelerate`、`gradio`、`torch`
- 有权限加载 LLaMA 3.1 的 Hugging Face access token
