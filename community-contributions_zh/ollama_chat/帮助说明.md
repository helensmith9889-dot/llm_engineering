# Ollama Chat — 使用帮助

一个通过 Ollama（OpenAI 兼容 API）与本地大模型聊天的 Streamlit Web 应用。

---

## 概述

本应用可以：

- 与运行在 Ollama 服务器上的模型聊天
- 从已安装模型中选择（自动加载列表）
- 查看每条助手回复的时间戳与 token 用量
- 清空对话，并可选择查看原始 API 响应（调试模式）

---

## 前置条件

1. **Python 3.9+**（推荐）
2. **已安装并运行 Ollama**
   - 下载：https://ollama.com
   - 默认 API：`http://localhost:11434`
3. **至少拉取一个模型**，例如：
   ```bash
   ollama pull gemma:2b
   ```

---

## 安装

1. 在项目文件夹（`ollama_chat`）中打开终端。
2. 创建并激活虚拟环境（可选但推荐）：
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # macOS/Linux
   source venv/bin/activate
   ```
3. 安装依赖：
   ```bash
   pip install streamlit openai requests
   ```

---

## 运行应用

```bash
streamlit run chat_app.py
```

浏览器应打开 `http://localhost:8501`。若未自动打开，请手动访问该地址。

---

## 使用方法

### 主聊天区

- 在底部输入框输入消息并按 Enter。
- 你的消息与助手回复会显示在聊天历史中。
- 每条消息显示时间戳；助手回复在可用时还会显示 token 计数（`in`、`out`、`total`）。

### 侧边栏设置

| 控件 | 说明 |
|--------|-------------|
| **Ollama Server URL** | API 基址。默认：`http://localhost:11434/v1`。若 Ollama 在其他机器或端口，请修改。 |
| **Choose a model** | 从 Ollama 服务器报告的模型中选择。应用加载时获取列表。 |
| **Clear Conversation** | 清除当前会话中的全部消息。 |
| **Show raw response** | 启用后尝试显示原始 API 响应 JSON，便于调试（见故障排查）。 |

---

## 工作原理

1. 应用通过 OpenAI Python 客户端连接 Ollama（`base_url` = 你的 Ollama URL，`api_key` = `"ollama"`）。
2. 可用模型从 `{ollama_host}/api/tags` 获取。
3. 每次新消息都会发送完整对话历史，以便模型具备上下文。
4. 对话状态仅保存在会话内存中，不会写入磁盘。

## 故障排查

### 出现 “Error” 或连接失败

- 确认 Ollama 正在运行：在终端执行 `ollama list`。
- 检查 **Ollama Server URL**（末尾需包含 `/v1`，例如 `http://localhost:11434/v1`）。
- 若使用远程服务器，确保主机可达，且防火墙允许 11434 端口。

### 模型列表为空或只显示 `gemma:2b`

- 若无法连接 Ollama，应用会回退到 `gemma:2b`。
- 拉取模型：`ollama pull <model-name>`，然后刷新应用（或更改 URL 以触发重新加载）。

### 响应缓慢

- 更大的模型需要更多 RAM/GPU，响应更慢。
- 模型刚加载后的首次请求可能较慢（预热）。

### 刷新后对话丢失

- 消息仅存在于 Streamlit 会话状态中。刷新页面会开启新会话。

### 调试模式无输出

- 若原始响应变量不在作用域内，调试复选框可能不显示输出。请查看聊天中的错误信息，或检查运行 Streamlit 的终端中的堆栈跟踪。

---

## 使用提示

- 切换话题时使用 **Clear Conversation**，避免旧上下文干扰模型。
- 远程 Ollama 可使用机器 IP：`http://192.168.x.x:11434/v1`。
- Token 计数取决于 Ollama 的 OpenAI 兼容 API 是否返回 usage 元数据。
