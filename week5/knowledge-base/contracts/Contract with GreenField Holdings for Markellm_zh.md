# 与 GreenField Holdings 就 Markellm 签订的合同

**生效日期：** 2023年11月15日  
**合同期限：** 12个月  

## 条款
1. **协议当事方**：本合同由 Insurellm（以下简称“提供方”）与 GreenField Holdings（以下简称“客户”）订立。
2. **服务范围**：提供方同意授予客户 Markellm 平台访问权限，使 GreenField Holdings 能够通过人工智能驱动的市场与潜在保险客户建立连接。
3. **合规**：双方同意遵守适用于信息安全与消费者数据保护的相关法律与法规。

## 续约
1. **自动续约**：本合同将自动续约连续一年期限，除非任何一方在当前期限届满前至少30日提供书面不续约通知。
2. **年度审查**：续约时，双方可审查并协商条款，包括根据第4节所述绩效指标对定价进行的任何修改。

## 功能
1. **人工智能驱动匹配**：访问先进算法，将 GreenField Holdings 与定制保险线索连接。
2. **实时报价**：能够向客户提供来自多家保险提供方的即时报价，促进更快的决策流程。
3. **定制化推荐**：利用可定制消费者画像增强营销策略并优化客户参与。
4. **数据洞察**：访问分析仪表板以获得市场趋势与消费者行为的实时洞察，帮助 GreenField Holdings 优化其产品组合。

## 支持
1. **客户支持访问**：客户将在正常营业时间内通过电话与电子邮件获得专属支持，以处理任何咨询或技术问题。
2. **培训与资源**：提供方将提供入职培训资源，确保 GreenField Holdings 能够有效使用 Markellm 平台。
3. **绩效评审**：将进行季度绩效评审，分析平台有效性、获客率与营销策略，确保双方目标一致。

## 定价
- **基础上市费**：GreenField Holdings 同意每月支付199美元，用于 Markellm 平台精选上市。
- **按绩效计费**：每获得一条客户线索另收取25美元费用，反映通过 Markellm 平台成功建立的连接。
