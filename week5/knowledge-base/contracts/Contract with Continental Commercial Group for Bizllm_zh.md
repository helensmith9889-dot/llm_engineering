# 与 Continental Commercial Group 就 Bizllm 签订的合同

**合同日期：** 2025年4月12日
**合同编号：** BZ-2025-E-0147
**当事方：**
- Insurellm, Inc.
- Continental Commercial Group, Inc.

---

## 条款

1. **覆盖范围：** Insurellm 同意向 Continental Commercial Group 提供 Bizllm Enterprise 平台的全面访问权限，包括白标能力、专属基础设施，以及用于全美50个州商业保险运营的完整 API 访问权限。

2. **期限：** 本协议自合同日期起有效期为36个月，并规定在第24个月时就可提前续约进行讨论。

3. **付款：** Continental Commercial Group 应按定制 Enterprise 定价在前12个月每月支付42,000美元；第2–3年的定价将根据使用指标与扩展功能采用情况进行审查与调整。

4. **保密：** 双方同意就本合作期间披露的专有算法、商业秘密、客户数据及商业策略保持最高级别保密。

5. **责任：** Insurellm 的责任限于直接损害，且不超过年度合同价值。Continental Commercial Group 持有覆盖数据泄露的2,500万美元网络安全保险。

6. **服务水平协议（SLA）：** Insurellm 保证平台可用性达99.9%，按月计量。每低于目标0.1%，Continental 获得当月费用5%的贷记，最高不超过当月费用的25%。

7. **排他性：** 在合同期限内，Continental Commercial Group 在北美特种建筑保险垂直领域享有 Bizllm 的排他使用权。

---

## 续约

本协议包含双方90日续约通知期。Continental Commercial Group 就为商业保险领域开发的任何新 Bizllm 功能或模块享有优先拒绝权。续约条款将根据平台演进、竞争格局与业务绩效指标协商确定。

---

## 功能

Continental Commercial Group 将获得完整的 Bizllm Enterprise 套件：

1. **白标定制：** 完整平台品牌化，含 Continental 徽标、配色方案，以及面向客户门户的自定义域名。

2. **专属云基础设施：** 私有云部署与专用服务器，确保数据隔离，并为 Continental 200+并发用户优化性能。

3. **无限 API 访问：** 完整 API 集成能力，无调用量限制，实现与 Continental 现有技术栈的无缝连接，包括：
   - Duck Creek 保单管理系统
   - Guidewire ClaimCenter
   - 定制数据仓库与商业智能平台
   - 第三方数据提供方（Verisk、ISO、Dun & Bradstreet）

4. **高级网络安全风险模块：** 全面网络保险核保工具，包括：
   - 自动化安全态势评估
   - 泄露历史分析与暗网监控
   - IT 基础设施漏洞扫描
   - 勒索软件风险评分

5. **定制产品配置：** 能够配置并部署无限数量的定制商业保险产品，包括特种险种，例如：
   - 建筑工程保证与总括计划
   - 环境责任
   - 董事与高级管理人员（D&O）保险
   - 雇佣行为责任（EPLI）

6. **预测分析引擎：** 机器学习模型用于：
   - 损失预测与准备金充足性
   - 最优定价建议
   - 续保概率评分
   - 交叉销售与追加销售机会识别

7. **代理人网络管理：** 企业级代理人门户，支持 Continental 3,500+独立代理人，具有分级权限、可定制佣金结构与实时保单绑定。

8. **监管合规套件：** 针对全部50个州的自动化合规监控，包括表格备案、费率审批跟踪与剩余市场要求。

---

## 支持

Insurellm 承诺提供全面的 Enterprise 级支持：

1. **专属成功团队：**
   - 指定首席客户官监督
   - 专属技术客户经理（TAM）
   - 持续优化的解决方案架构师
   - 有 C 级高管参与的季度高管业务评审

2. **24/7/365 支持：**
   - 关键问题保证15分钟响应时间
   - 高优先级问题1小时响应
   - 专属 Slack 频道用于实时沟通
   - 月度系统健康报告与优化建议

3. **实施与入职：**
   - 为期6个月的实施计划，配备专属项目经理
   - 最多150名 Continental 员工的综合培训
   - 定制培训材料与认证计划
   - 生产运营前90日的现场支持

4. **开发与定制：**
   - 每年包含500小时定制开发
   - 优先功能请求并保证评估
   - 所有新功能在正式发布前60日获得测试版访问权限
   - 参与产品路线图与战略方向输入

5. **数据服务：**
   - 季度数据质量审计
   - 系统升级的年度数据迁移支持
   - 具有7年留存的专属数据仓库
   - 定制报告与分析仪表板开发

6. **性能优化：**
   - 月度平台性能评审
   - 主动容量规划与扩展建议
   - 重大产品上线前的负载测试
   - 带实时告警的专属基础设施监控
