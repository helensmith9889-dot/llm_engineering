# 综合测试数据生成器

第 3 周课程项目 — 使用本地 LLM 为 REST API 生成真实的 JSON 有效负载。

## 它的作用

采用 OpenAPI 规范，提取请求主体架构，并使用量化语言模型生成符合这些架构的综合测试数据。

## 它是如何工作的

1. 解析 OpenAPI 规范 (JSON) 并提取端点架构
2. 解析 `$ref` 引用以获得平面 JSON 模式定义
3. 根据模式构建提示并将其发送到本地 4 位量化模型
4. 从模型的响应中提取 JSON 并根据原始模式对其进行验证

## 模型比较

|型号|参数|有效的 JSON |模式匹配|笔记|
| :-----: | :--------: | :------------: | :--------------: | :-----: |
|骆驼 3.1 8B 指导 | 8B |是的 |是的 |最佳结果 — 干净的数组、正确的结构 |
| Qwen 2.5 Coder 7B 指导 | 7B|是的 |是的 |简洁的单对象输出 |
| Phi 4 迷你指导 | 3.8B|是的 |没有 |回显模式定义，将数据嵌套在“data”键下 |

所有模型均通过 BitsAndBytes 量化为 4 位 (NF4)。使用最少的提示进行测试（没有少量示例）。

## 设置

需要支持 CUDA 的 NVIDIA GPU。首先安装支持 CUDA 的 PyTorch，然后安装依赖项而不解析 torch：```bash
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install --no-deps accelerate bitsandbytes transformers huggingface_hub[hf_xet]
```需要“.env”中的 Hugging Face 令牌作为“HF_TOKEN”（Llama 需要访问批准）。
