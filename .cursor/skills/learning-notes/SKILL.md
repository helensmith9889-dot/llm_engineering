# 学习笔记落盘

本仓库的**学习笔记**习惯：解释可以只聊；要沉淀就写进 `python学习笔记/`。  
权威路由也写在仓库根 [`AGENTS.md`](../../../AGENTS.md)。

## 步骤

### 1. 先解释

用简洁中文讲清当前问题（可含短代码 / 对照表）。  
**完成标准**：用户问的点已答到，且未先写文件。

### 2. 追问是否落盘（必做）

解释后**必须**问一句，例如：

> 需要我把这段保存到 `python学习笔记/` 吗？

**完成标准**：已发出追问；在用户表态前**不**创建或改笔记文件。

例外（跳过追问，直接写）：

- 用户已明确说「写到笔记」「保存」「记下来」「同步到 python学习笔记」等。

### 3. 确认后按路由追加

| 内容 | 文件 |
|------|------|
| Python 基础 + 与 JS 对照 | `python学习笔记/基础语法.md` |
| LLM / Prompt / Tools / RAG / 微调等 | `python学习笔记/llm.md` |
| Gradio 专题 | `python学习笔记/Gradio.md` |

写法（对齐现有笔记）：

1. 文首或小节注明 `> 来源：...`
2. 小节标题清楚；代码块 + 简短说明
3. 需要时给 Python ↔ JS 对照表
4. 可附 2～3 道小练习
5. **追加**新小节，不无故覆盖全文

**完成标准**：目标文件已更新；路径告知用户。

### 4. 用户拒绝保存

只保留对话中的解释，不改 `python学习笔记/`。  
**完成标准**：无笔记文件变动。
