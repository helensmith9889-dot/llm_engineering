# AiForAll 助手练习

本目录是一个面向 AiForAll 问答助手的检索增强生成（RAG）演示。

## 概述

- `app.py`：启动 Gradio Web UI，支持聊天问答
- `answer.py`：从知识库取相关上下文，并用大模型生成回答
- `ingestion.py`：从 `docs/` 摄入 Markdown，分块、嵌入并写入 `preprocessed_db`
- `crawler.py`：爬取文档站点，保存 Markdown 到 `docs/` 供摄入
- `eval.py`：从检索相关性、忠实度、完整性、回答相关性等维度评估答案
- `prompts.py`：评审模块使用的评估系统提示词
- `docs/`：检索用知识库文档
- `preprocessed_db/`：Chroma 向量库

## 依赖

至少需要：`gradio`、`matplotlib`、`python-dotenv`、`langchain`、`langchain_community`、`langchain_chroma`、`langchain_openai`、`chromadb`、`openai`、`litellm`、`pydantic`、`tenacity`

```bash
uv sync
```

## 设置

1. 在本目录或仓库根目录创建 `.env`：
```env
OPENAI_API_KEY=your_openai_api_key
```

2. 激活 Python 环境。

3. 爬取目标文档到 `docs/`：
```bash
uv run community-contributions/ashutosh/Week5/excercise/crawler.py
```

4. 摄入向量库：
```bash
uv run community-contributions/ashutosh/Week5/excercise/ingestion.py
```

## 运行聊天应用

```bash
uv run community-contributions/ashutosh/Week5/excercise/app.py
```

Gradio 界面会在浏览器打开，可查看：生成回答、检索上下文、评估指标。

## 说明与排错

- 若找不到嵌入，请重跑 `python ingestion.py`
- 模型失败时检查 `OPENAI_API_KEY`
- UI 起不来时确认依赖已安装
- 若 `preprocessed_db/` 已存在且未更新 `docs/`，可跳过摄入
