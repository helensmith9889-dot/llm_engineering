## 为什么算「优质」

入选通常满足多数条件：

1. **不是课内逐字翻版**：与官方 `day1`/`day2`/… 代码重合度低，或有明确独特场景/技术选型
2. **练习目标清楚**：解决一个可说清的问题（客服、JIRA、赛况、美妆顾问、合成数据、RAG、定价、微调、多智能体等）
3. **能力点可迁移**：能对应到当周课程概念，做完能复述「我练了什么」
4. **闭环相对完整**：输入→模型/工具→输出（有的还带 UI），而不是只跑通一格 API
5. **可对照学习**：适合在学完当周课内实验后，当作周末加练或作品集素材

> 优质 ≠ 完美。部分 notebook 依赖 Colab、付费 API 或旧版库；跟做时以思路与结构为主，环境按你的机器调整。
