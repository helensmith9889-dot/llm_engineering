# 🧠 Agentic 语音/文本支持聊天机器人

多模式聊天机器人界面，支持**文本和语音输入**、**多种大型语言模型 (LLM)** 和 **上下文记忆持久性** - 所有这些都在一个基于 Gradio 的 GUI 中。

## 🚀 特点

- 🔄 **多 LLM 切换**：在 OpenAI、Anthropic Claude 和 Meta LLaMA 之间动态切换（通过 Ollama）
- 🎤 **语音输入**：使用麦克风进行实时语音到文本转录
- 💬 **上下文记忆**：即使在切换模型时也能保留聊天记录
- 🧪 **原型就绪**：使用 Gradio 构建，用于快速 GUI 测试和开发

## 🛠️ 使用的技术

- [Gradio](https://www.gradio.app/) – GUI界面
- [OpenAI API](https://platform.openai.com/)
- [人类克劳德 API](https://www.anthropic.com/)
- [Ollama](https://ollama.com/) – 本地 LLaMA 推理
- [`speech_recognition`](https://pypi.org/project/SpeechRecognition/) – 语音到文本
- `sounddevice`、`numpy` – 录音
- `.env` – 环境变量管理

## 您还需要：
- OpenAI 和 Claude 的 API 密钥
- Ollama 在本地安装以运行 LLaMA 模型
- 包含必要 API 密钥的 .env 文件
