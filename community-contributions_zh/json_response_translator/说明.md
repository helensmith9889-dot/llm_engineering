# JSON 西班牙语翻译 API

一个基于 FastAPI 的简单微服务：在**保持原始 JSON 结构不变**的前提下，把 **JSON 字段名及其对应值翻译成西班牙语**。

------------------------------------------------------------------------

## 功能特性

-   接受任意合法 JSON 载荷
-   将字段名与值翻译成西班牙语
-   保持原始 JSON 结构
-   返回严格合法的 JSON
-   确定性输出（`temperature=0`）
-   自动生成 Swagger UI 文档

## 安装

### 1. 创建虚拟环境（推荐）

```bash
python -m venv venv
```

激活：

**Windows**

```bash
venv\Scripts\activate
```

**Mac/Linux**

```bash
source venv/bin/activate
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

------------------------------------------------------------------------

## 环境变量

创建 `.env` 文件：

    OPENAI_API_KEY=your_openai_api_key_here

------------------------------------------------------------------------

## 运行应用

```bash
uvicorn main:app --reload
```

API 地址：

    http://127.0.0.1:8000

Swagger 文档：

    http://127.0.0.1:8000/docs

------------------------------------------------------------------------

## API 端点

### POST `/translate-json`

#### 请求示例

```json
{
  "name": "John Doe",
  "city": "New York",
  "orderStatus": "Pending"
}
```

#### 响应示例

```json
{
  "nombre": "Juan Doe",
  "ciudad": "Nueva York",
  "estadoPedido": "Pendiente"
}
```

------------------------------------------------------------------------

## 工作原理

1.  接收 JSON 载荷
2.  将 JSON 转为字符串
3.  请求 OpenAI 模型（`gpt-4.1-nano`）
4.  强制结构化 JSON 输出
5.  返回翻译后的 JSON

------------------------------------------------------------------------

## 可选 Docker 部署

### Dockerfile

```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 构建并运行

```bash
docker build -t spanish-translator .
docker run -p 8000:8000 --env-file .env spanish-translator
```
