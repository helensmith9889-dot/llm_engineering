## 生物医学文献摘要器（Europe PMC + Ollama）

这是一个简单应用：借助 Europe PMC API 与 Ollama LLM，为生物医学文献生成简洁摘要。

## 🔍 关于 Europe PMC（EPMC）
Europe PMC 是一个免费开放的数据库，可检索数百万篇生命科学与生物医学文章、论文与预印本，属于 PubMed Central International（PMCI）网络的一部分。

## 功能

本方案提供两种使用方式：
1. Jupyter Notebook 简易演示
2. 本地 Gradio 交互演示

**核心能力：**
- 通过 Europe PMC API（提供 PMCID）获取文章元数据与摘要
- 预处理并清理摘要文本中的无用标签（如引用标签、数学公式等）
- 用 Ollama 模型将摘要整理为要点列表 + 短段落

## 📌 如何使用

- 打开 [Europe PMC 网站](https://europepmc.org/)。
- 用关键词、实体名、期刊或作者搜索开放获取文章，例如 Genes、Diseases、nutrition 等。
- 本应用目前只支持开放获取文章，请用 `HAS_FT:Y` 或 `IN_EPMC:Y` 等过滤，例如：`"Genes: HAS_FT:Y"`。
- 选中感兴趣的文章，复制其 PMCID（如 PMC1234567）。

- 运行摘要器：
  - Notebook：把 `PMCID` 作为字符串粘贴到 notebook 中
  - Gradio：在界面输入框填入 PMCID 并提交

## 依赖与运行

请安装项目依赖，并确保本地已启动 Ollama 且拉取了所需模型。详情见 notebook / Python 脚本内注释。
