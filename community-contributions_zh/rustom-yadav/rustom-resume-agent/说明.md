# 简历构建智能体（Resume Builder Agent）

一个对话式 AI 智能体：通过结构化提问引导用户，生成专业 HTML 简历。

## 注意
生成 `final_resume.html` 后，你需要格式化该文件，因为全部代码写在一行里。可用在线 HTML 格式化工具，或带格式化能力的代码编辑器使其可读。

## 工作原理

智能体会：

1. 依次提出 7 个问题，收集简历信息
2. 用提供的数据更新 HTML 简历模板
3. 生成完成的 `final_resume.html` 文件

## 环境搭建

1. 安装依赖：

```bash
pip install -r requirements.txt
```

2. 创建 `.env` 文件：

```env
BASE_URL=http://localhost:11434/v1
API_KEY=ollama
MODEL_NAME=llama3.2:latest
```

3. 将 `resume_template.html` 模板放在同目录

4. 运行脚本：

```bash
python resume-builder-agent.py
```

## 自定义

- **更换 AI 模型**：在 `.env` 中更新 `MODEL_NAME`，可用任意兼容 OpenAI SDK 的模型（OpenAI、Ollama、Azure 等）
- **自定义简历**：编辑 `resume_template.html` 以修改模板结构与样式

## 支持的 API

适用于任何兼容 OpenAI SDK 的 API：

- Ollama（本地）
- Groq API 与模型
- OpenAI
- Azure OpenAI
- 其他兼容提供商
