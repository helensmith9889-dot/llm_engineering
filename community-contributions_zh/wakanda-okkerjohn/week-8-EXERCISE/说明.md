# 独立发行商和融资机会匹配器

**第 8 周风格的代理解决方案，解决游戏行业真正的痛点：独立开发者需要在正确的时间找到正确的发行商/基金；手动跟踪很痛苦。**

---

## 为什么这对你很重要（独立开发者）

作为一名独立开发者，您正忙于开发游戏。您没有时间：

- 检查每个出版商的“我们开放提交”页面。
- 记住哪些基金（ID@Xbox、Epic MegaGrants、独立基金等）适合您的范围。
- 重新阅读提交指南，看看您是否匹配。

**这个工具：**

- 保留**发行商和资助机会**的列表（Pixel Forge 风格、ID@Xbox、PlayStation 合作伙伴、Humble、独立基金、Epic MegaGrants、任天堂等）。
- **为每项评分** (0–100)，衡量其适合典型独立游戏的程度：独奏/小团队、6–18 个月范围、PC/主机、独立游戏友好类型。
- 在一张表中显示**最适合**，并且当某些分数高于阈值时可以**提醒您**（例如推送通知）。

因此，与其手动跟踪“谁有空？”和“我符合资格吗？”，您进行扫描，查看排序的机会，并对重要的机会采取行动。

## 如何使用

- 您可以独立运行该项目，在设置过程中，您需要首先设置虚拟环境（venv），然后将包安装在requirements.txt 文件中。
- 在根项目中创建 .env 文件。
- 您可以看到下面的设置，了解它是如何完成的。

1. **设置一次** – 安装 deps，将 `OPENROUTER_API_KEY` 添加到 `.env`。
2. **打开应用程序** – 运行`python app.py`； Gradio UI 将在浏览器中打开。
3. **运行扫描** – 单击**“运行扫描并评分”**。该应用程序加载机会，使用 RAG + LLM 对其进行评分，并将最佳的新机会添加到表中（使用 **Fit** 0–100 和 **URL**）。
4. **使用表格** – 按 **适合** 排序以查看最佳匹配。单击一行可重新发送该机会的推送警报（如果设置了 Pushover）。
5. **当您关心时重复** – 每周或在准备推介之前进行扫描；列表不断增长，您只能看到新的 + 得分机会。

**可选：** 将您自己的程序添加到`opportunities_data.json`；降低或提高“config.py”中的拟合阈值。

## 适合度分数 (0–100) 是什么意思？

- **适合度**是指机会与典型独立类型的匹配程度：单人/小团队、6-18 个月的范围、PC/主机、独立友好类型（类 Rogue、解谜、叙事、战术等）。它是 (1) RAG 与游戏发行商 KB 和 (2) LLM“独立适合”分数的加权组合。
- **更高（例如 70–100）** – 强匹配：标准、范围和可访问性很好。值得优先考虑。
- **中值（例如 50）** – **要么** 是真正的“还可以”匹配（不是明显好或错），**或者**我们无法正确评分（例如没有 RAG 上下文、API 错误或无法解析的回复），所以我们回落到 50。将 50 视为“自己检查一下”而不是“这是一个完美的中间分数”。
- **较低（例如 0–40）** – 不适合典型的独立形象（例如错误的范围、平台或类型）。

**一切都在 week8** – 知识库和矢量存储包含在该项目中并自动构建。

这个项目：

- **扫描**策划的出版商/资助机会（尚无手动 RSS；您可以添加更多来源）。
- **为每个机会得分**：
  - **RAG** 超过本地 **游戏发行商-kb**（Pixel Forge 风格标准：类型、范围、平台）。该知识库位于“game-publisher-kb/”中，如果缺少，Chroma DB 会在首次运行时构建。
  - **LLM** 适合“典型的独立开发者”（独奏/小团队，6-18 个月，PC/主机）。
- **Ensemble** 将 RAG + LLM 合并为一个适合分数 (0–100)。
- **规划**代理选择最佳的新机会，如果高于阈值，**提醒**您（Pushover）。
- **Gradio UI** 显示出现的机会； “运行”运行一个扫描/评分周期； row select 可以重新发送警报。

## 先决条件

- **Python 3.10+** （或使用 `uv`）。
- `.env` 中的 **OpenRouter API 密钥**：“OPENROUTER_API_KEY=...”。
- **可选：** `OPENROUTER_MODEL`（默认为`openai/gpt-4o-mini`）。

## 设置

从匹配器目录：

```bash
pip install -r requirements.txt
```

在此目录（或存储库根目录）中创建一个“.env”，至少包含：

```
OPENROUTER_API_KEY=sk-or-v1-...
```

## 运行用户界面

```bash
python app.py
```

第一次运行时，矢量存储是从“game-publisher-kb/”构建的（可能需要一分钟）。然后打开“Gradio”选项卡，单击“**运行扫描和评分**”运行一个周期。

```bash
python build_vectorstore.py
```

```bash
python publisher_framework.py
```

## 配置

- **`config.py`**
  - 所有路径均为本地路径（无第 5 周）。 `game_publisher_db` 是在该项目内创建的。
  - `FIT_THRESHOLD`（默认 60）：发送警报的最低适合分数。
  - `MAX_OPPORTUNITIES_PER_RUN`：每次运行有多少个新得分机会。
- **`game-publisher-kb/`**：markdown 文档（提交、收入、平台、团队、标题）。编辑这些以更改 RAG 上下文。
- **`opportunities_data.json`**：精选的机会列表。添加或编辑条目；扫描仪会排除内存中已有的 URL。
