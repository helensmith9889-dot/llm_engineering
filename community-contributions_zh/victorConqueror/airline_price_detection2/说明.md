# 航空公司价格检测机器人

这是一款由 LangChain 和 OpenAI 提供支持的 Gradio 应用程序，可以从给定的 URL 检测机票价格和目的地。

## 特点
* **AI Tool Calling Agent**：使用 `gpt-4o-mini` 智能决定何时抓取网页。
* **自定义 Web Scraper**：一种嵌入式工具，可提取货币符号（包括 $、€、£ 和 ₦）附近的文本。
* **Gradio Interface**：提供用户友好的聊天 UI，用于与 AI 代理交互。

## 先决条件
* 您必须安装Python。
* 您需要一个 OpenAI API 密钥。

## 安装

1. 确保安装了所需的 LangChain 和 Gradio 软件包（如果您安装了项目依赖项，则它们应该已经安装：`pip install -rrequirements.txt`）。 
2. 设置环境变量：
   ```bash
   # On Windows
   set OPENAI_API_KEY="your-api-key-here"
   
   # Or create a .env file containing:
   # OPENAI_API_KEY="your-api-key-here"
   ```

## 运行应用程序

```shell
python app.py
```

Then visit the URL outputted in the terminal (usually `http://127.0.0.1:7860`).

询问机器人：*“[URL] 上提到的目的地的价格是多少？”*
