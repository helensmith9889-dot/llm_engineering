# 高层真相顾问（High-Level Truth Advisor）

本项目是一个基于 Jupyter Notebook 的工具，定位为**极度坦诚的高层顾问与镜子**。它通过 Groq API 调用大语言模型（LLM），针对各类人生与职业情境，提供不加滤镜、理性且具有战略深度的反馈。

## 概述

**高层真相顾问**旨在挑战你的思维、暴露盲点，并给出优先排序的改进计划。它不提供安慰，而是聚焦于真正成长所需的「残酷真相」。

### 主要特性
- **极度坦诚的反馈：** 不粉饰、不奉承。
- **深度战略分析：** 以客观与战略深度审视情境。
- **可执行计划：** 给出心态与行动改变的精确优先级路线。
- **无缝集成：** 使用 Groq 高速 API 与 Llama 3 模型。

## 环境准备

1. **环境变量：**
   在同目录创建 `.env`，并写入 Groq API Key：
   ```env
   GROQ_API_KEY=your_groq_api_key_here
   ```

2. **依赖：**
   确保已安装：
   ```bash
   pip install openai python-dotenv ipython
   ```

3. **运行笔记本：**
   在 Jupyter 环境（VS Code、JupyterLab 等）中打开 `Harsh_truth.ipynb`（中文副本为 `第1天_残酷真相.ipynb`）并运行单元格。

## 工作原理

顾问使用特制的**系统提示**，指示 AI：
- 充当镜子并挑战假设。
- 指出自我欺骗或时间浪费。
- 避免一味肯定与奉承。
- 提供迈向下一步成长的优先级计划。

### 示例提问
> "Is it good that I have worked in 3 different domain of Projects and still I don't have indepth knowledge of any domain?"

AI 会客观分析利（视野广、适应力）与弊（缺乏专长、职业发展受限），并给出专业化路线图。

## 项目结构
- `Harsh_truth.ipynb` / `第1天_残酷真相.ipynb`：主笔记本（逻辑与提示词）。
- `.env`：（用户自建）存放 API 凭证。
