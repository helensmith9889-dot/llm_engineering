# 与 Apex Reinsurance 就 Rellm：AI 驱动的企业再保险解决方案签订的合同

## 条款

1. **当事方**：本合同（“协议”）由 Insurellm, Inc.（“提供方”）与 Apex Reinsurance（“客户”）于本[日期]订立。

2. **服务范围**：提供方同意交付 Rellm 解决方案，包括人工智能驱动分析、无缝集成、风险评估模块、可定制仪表板、监管合规工具，以及产品摘要中所述的客户与经纪人门户。

3. **付款条款**：客户应按每月10,000美元向提供方支付本协议期间费用。款项于每月首日到期，并通过电子资金转账处理。

4. **合同期限**：本协议自[起始日期]起生效，有效期为十二（12）个月，除非根据本协议所载条款提前终止。

## 续约

1. **自动续约**：本协议将自动续约连续一年期限，除非任何一方在当前期限届满前至少三十（30）日提供书面终止意向通知。

2. **续约定价**：续约时，定价可由提供方进行调整。提供方将就任何定价变更提前至少六十（60）日发出通知。

## 功能

1. **人工智能驱动分析**：Rellm 平台将利用人工智能算法提供风险敞口的预测洞察，使客户能够借助实时数据分析作出知情决策。

2. **无缝集成**：Rellm 的架构便于与客户现有系统轻松集成，包括保单管理与理赔处理系统。

3. **可定制仪表板**：仪表板将按客户运营需求定制展示指标，提升生产力并促进更高效的数据访问。

4. **监管合规**：该解决方案将包含合规跟踪功能，协助客户持续遵守相关法规。

5. **专属客户门户**：客户门户将促进实时沟通与文件共享，确保合作全程无缝协作。

## 支持

1. **技术支持**：提供方应在营业时间（周一至周五，东部时间上午9时至下午5时）通过电话、电子邮件及工单系统向客户提供专属技术支持。

2. **培训与入职**：提供方将为客户最多十（10）名员工提供全面入职培训，以确保有效使用 Rellm 解决方案。

3. **更新与维护**：提供方负责提供 Rellm 平台更新以改进功能与安全性，客户无需额外付费。

4. **升级协议**：无法在一线支持解决的问题将升级至高级支持团队，确保关键问题得到及时处理。
