# 与 GlobalRe Partners 就 Rellm — AI 驱动的企业再保险解决方案签订的合同

**合同日期：** 2025年4月28日
**合同编号：** RE-2025-E-0203
**当事方：**
- Insurellm, Inc.
- GlobalRe Partners International, Ltd.

---

## 条款

1. **覆盖范围：** Insurellm 同意向 GlobalRe Partners 提供 Rellm 平台的企业级访问权限，包括白标能力、无限合约再保险与临时再保险管理、专属基础设施，以及用于其全球再保险运营的完整 API 访问权限。

2. **期限：** 本协议自合同日期起有效期为48个月，代表 Insurellm 最具战略意义的长期再保险合作关系。

3. **付款：** GlobalRe Partners 应按定制 Enterprise Tier 定价在第1–12个月每月支付45,000美元，第13–24个月每月支付48,000美元，第25–36个月每月支付52,000美元，第37–48个月每月支付56,000美元，合同期内合计2,412,000美元。

4. **再保险量**：Enterprise Tier 支持无限合约与临时再保险凭证。GlobalRe 目前管理450+合约关系，每年完成8,000+临时再保险安排。

5. **服务水平协议：** Insurellm 保证平台可用性达99.95%，按月计量；每发生一小时非计划停机给予当月10%贷记，最高不超过当月费用的50%。

6. **保密：** 双方同意就专有人工智能算法、再保险定价模型、分出人数据、巨灾建模及战略举措保持最高级别保密。

7. **数据安全：** Insurellm 维持 SOC 2 Type II 合规、ISO 27001 认证，以及含渗透测试的年度第三方安全审计。

8. **业务连续性：** 保证2小时恢复时间目标（RTO）与30分钟恢复点目标（RPO），并配备地理分散的数据中心。

9. **全球运营：** 平台支持多币种（35+币种）、多语言（12种语言）与多司法管辖区监管合规。

---

## 续约

本协议包含双方120日续约通知期。GlobalRe Partners 享有最惠客户定价保证，并优先获得所有新再保险功能访问权限。合同可以12或24个月增量延期，并就巨灾建模与气候风险分析的联合创新举措作出规定。

## 功能

GlobalRe Partners 将获得完整的 Rellm Enterprise 套件及高级再保险能力：

1. **无限再保险管理：** 全面支持 GlobalRe 的450+合约关系与每年8,000+临时再保险安排，并可扩展至1,000+合约与50,000+临时再保险凭证。

2. **白标平台：** 完整品牌定制：
   - 自定义域名（portal.globalrepartners.com、cedents.globalrepartners.com、brokers.globalrepartners.com）
   - 面向分出人、经纪人与转分保接受人的品牌门户
   - 多语言界面（英语、西班牙语、法语、德语、普通话、日语、葡萄牙语、荷兰语、意大利语、韩语、阿拉伯语、俄语）
   - 定制报告模板与市场演示材料

3. **高级人工智能驱动分析：** 企业级再保险分析：
   - 跨所有业务线的预测性风险建模
   - 合约投资组合优化与资本配置
   - 转分保优化与保障塔设计
   - 含市场周期情报的定价分析
   - 损失发展与 IBNR 预测
   - 含置信区间的最终损失预测
   - 准备金充足性建模
   - 通融结清机会识别

4. **综合风险评估模块：** 先进风险评估：
   - 含早期预警指标的分出人财务实力分析
   - 跨所有合约的投资组合敞口汇总
   - 冲突分析与累积监控
   - 地理集中度热力图
   - 行业与业务线多元化指标
   - 新兴风险识别（网络、气候、疫情）
   - 交易对手信用风险评估
   - 转分保信用风险监控

5. **巨灾建模集成：** 一流 CAT 建模：
   - 与所有主要供应商集成（RMS、AIR、CoreLogic、KCC）
   - 多风险巨灾分析
   - 所有回归期的可能最大损失（PML）计算
   - 超越概率曲线与尾部风险价值
   - 气候变化情景建模
   - 二次不确定性与模型融合
   - 实时 CAT 事件跟踪与损失估算
   - 灾前敞口管理与灾后理赔预测

6. **合约管理：** 完整合约生命周期管理：
   - 合约结构设计与成数再保险优化
   - 超额赔款分层优化
   - 滑动比例佣金计算
   - 损失走廊与累计免赔额跟踪
   - 恢复保费自动化
   - 现金催缴处理与保费分摊
   - 损失准备金清单处理
   - 合约会计与对账
   - 多年期合同管理

7. **临时再保险平台：** 全面临时再保险管理：
   - 来自经纪人与分出人的数字化提交受理
   - 人工智能驱动的核保决策支持
   - 自动化风险分级与定价建议
   - 同业定价比较与市场情报
   - 含条款与条件的报价生成
   - 临时保单与凭证签发
   - 按凭证跟踪保费与理赔
   - 投资组合监控与汇总

8. **可定制仪表板：** 企业级分析：
   - 实时投资组合绩效指标
   - 按合约、分出人、业务线、地理区域跟踪综合比率
   - 保费规模与增长分析
   - 理赔发展与赔付率趋势
   - 准备金充足性指标
   - 资本利用率与 ROE 分析
   - 市场份额与竞争定位
   - 经纪人与分出人关系指标

9. **监管合规工具：** 全球合规支持：
   - 多司法管辖区监管报告（美国、欧盟、英国、亚太、拉丁美洲）
   - 欧洲运营的偿付能力 II（Solvency II）合规
   - IFRS 17 报告与分析
   - 美国法定会计（SAP）
   - 税务报告与预扣管理
   - 制裁筛查（OFAC、联合国、欧盟）
   - 反洗钱（AML）监控
   - 审计跟踪与文档库

10. **客户与经纪人门户：** 利益相关方参与平台：
    - 分出人门户，用于提交、清单、报告与分析
    - 经纪人门户，用于报价请求、绑定与佣金
    - 转分保接受人门户，用于下游安排
    - 实时数据共享与文件交换
    - 安全消息与协作工具
    - 移动应用访问，支持随时随地使用
    - 按关系定制的视图

11. **完整 API 访问：** 无限 API 集成：
    - 与 GlobalRe 核心系统实时集成
    - 会计系统集成（SAP、Oracle）
    - 数据仓库同步
    - 巨灾建模平台连接
    - 经纪人交易平台（Ebix、Sequel）
    - 劳合社平台集成（Whitespace、PPL）
    - 行业数据提供方（AM Best、S&P、Moody's）
    - 经济与市场数据馈送

12. **高级转分保管理：** 转分保优化：
    - 转分保计划结构设计
    - 保障塔分析与缺口分析
    - 转分保市场情报与定价
    - 交易对手多元化优化
    - 信用风险监控
    - 担保品管理
    - 转分保追偿跟踪

13. **气候风险分析：** 前瞻性气候建模：
    - IPCC 气候情景分析（RCP 2.6、4.5、8.5）
    - 转型风险评估
    - 针对风险因素的物理风险建模（飓风、野火、洪水、干旱）
    - 海平面上升影响分析
    - 温度趋势纳入
    - 气候调整定价建议
    - 搁浅资产识别
    - 绿色再保险机会
