# 招聘启事 → 一页纸摘要

把招聘广告整理成结构化的**一页纸**，方便你投递：岗位摘要、关键要求、建议求职信要点，以及简历应包含的关键词。

灵感来自第 1 周（抓取/获取 + LLM）。支持：

- **URL**：抓取招聘页面（公司招聘站、Greenhouse 等）。
- **粘贴文本**：当页面需登录或难以抓取时（如 LinkedIn），粘贴完整职位描述。

## 环境准备

使用主仓库环境。从仓库根目录：

```bash
cd community-contributions/job-posting-one-pager
```

确保仓库根目录（或本文件夹）有 `.env`，并包含：

```
OPENAI_API_KEY=your_key_here
```

依赖已在主仓库 `pyproject.toml`（openai、beautifulsoup4、requests、python-dotenv）。

## 用法

### Jupyter 笔记本（推荐）

```bash
# 在仓库根目录
jupyter notebook community-contributions/job-posting-one-pager/job_one_pager.ipynb
```

运行单元格：设置 `url` 或 `pasted_job` 文本，然后调用 `generate_one_pager(...)`，并用 `Markdown()` 展示。

### Python

```python
from one_pager import generate_one_pager

# 从 URL
one_pager = generate_one_pager("https://company.com/careers/role")

# 从粘贴文本（如 LinkedIn）
one_pager = generate_one_pager('''
Senior Engineer – Backend
Company X – Remote
Requirements: 5+ years Python...
''')

print(one_pager)
# 或保存：open("one_pager.md","w").write(one_pager)
```

### 命令行

在本目录下：

```bash
# URL
python -m one_pager "https://example.com/job"

# 从 stdin 粘贴文本
echo "Paste job description here..." | python -m one_pager
```

或直接粘贴（无 URL）：

```bash
python -m one_pager "Senior Engineer. Requirements: 5+ years..."
```

## 输出章节

一页纸包含：

- **Role summary（岗位摘要）** – 2–3 句说明级别与重点
- **Key requirements（关键要求）** – 招聘启事中的硬性条件
- **Nice-to-haves（加分项）** – 优先但非必须的技能/经验
- **Suggested cover letter bullets（建议求职信要点）** – 3–5 条「我为何合适」的第一人称要点
- **Keywords to include in resume（简历关键词）** – 需呼应广告中的术语

## 说明

- LinkedIn 与部分招聘板会屏蔽或限制抓取；对这些站点请用**粘贴文本**。
- 过长的启事会截断到 8,000 字符，以适配上下文限制。
- 默认模型：`gpt-4o-mini`。需要时可 `generate_one_pager(..., model="gpt-4o")` 覆盖。
