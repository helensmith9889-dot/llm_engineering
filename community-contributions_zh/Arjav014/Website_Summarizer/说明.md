# 网站摘要器

轻量 Python 工具：抓取任意网站内容并摘要。先提取干净正文（去掉页眉页脚、样式与脚本），再调用 LLM 生成结构化、易读的 Markdown 摘要。

## 功能

- **去模板噪声**：去掉导航、页眉页脚、样式与 script，降低 token 消耗。
- **稳健抓取**：`requests` + 自定义 `User-Agent` 与超时，规避基础反爬。
- **结构化摘要**：系统提示词优化为输出干净 Markdown。

## 项目结构

- `scraper.py`：用 BeautifulSoup 抓取并清理网页 HTML 文本
- `main.ipynb`：用户界面 Notebook：导入爬虫、接收输入、调用 LLM
- `requirements.txt`：依赖列表

## 安装与运行

```bash
cd Website_Summarizer
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook main.ipynb
```

## 配置

`main.ipynb` 默认通过 Ollama 连接 LLM：
```python
OLLAMA_BASE_URL = "http://localhost:11434/v1"
ollama = OpenAI(base_url=OLLAMA_BASE_URL, api_key='ollama')
```
请确保本地 Ollama 已运行；也可改为 OpenAI 或其他提供商。
