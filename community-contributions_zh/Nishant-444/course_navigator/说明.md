# 课程导航器和 RAG 助理

**Nishant Sharma** 的社区贡献。

**课程导航器和 RAG 助手**是一个独立的 RAG（检索增强生成）系统，旨在帮助学生搜索、导航并与 **LLM 工程**课程中的所有材料进行聊天。

它解析并索引所有官方每周笔记本（“week1”到“week8”）、Python 脚本和技术指南。通过使用本地语义嵌入和向量数据库，它使您能够提出基于课程的问题，并通过直接文件引用获得即时、准确的答案。

---

## ✨ 特点

- **本地语义搜索**：使用 `sentence-transformers/all-MiniLM-L6-v2` 在本地免费生成 384 维文本嵌入。使用“numpy”计算余弦相似度以立即检索最相关的部分。
- **上下文 AI 答案**：将相关代码库部分馈送到自定义系统提示中，并使用您的环境凭据查询 OpenRouter (`google/gemini-2.5-flash`)。
- **低成本 API 优化**：限制响应令牌以保持在低预算限制内。
- **Premium Gradio Web 界面**：包括响应式暗模式聊天和探索仪表板。
- **Jupyter Notebook 演示**：包括以编程方式演示 RAG 操作的分步笔记本。

## 🚀 快速入门指南

### 1. 设置依赖项
确保您使用项目根目录中的虚拟环境“.venv”。如果您还没有这样做，请运行安装程序。
如果需要手动安装依赖：```bash
pip install sentence-transformers gradio openai python-dotenv numpy
```### 2. 构建搜索索引
运行索引器脚本来解析存储库并生成向量嵌入。它将扫描所有指南和周（自动跳过隐藏文件、“.venv”和其他学生提交的文件）：```bash
python indexer.py
```*（此过程在第一次运行时下载一个约 120MB 的小型本地嵌入模型，并需要大约 1-2 分钟来对所有文本块进行编码）。*

### 3.启动Web界面
启动交互式 Gradio Web 应用程序：```bash
python app.py
```打开浏览器并导航到终端中打印的本地链接（通常为“http://127.0.0.1:7860”）。

### 4. 交互式笔记本演练
或者，您可以在 Cursor/VSCode 中打开并运行“course_navigator.ipynb”，以编程方式检查搜索分数和响应负载。
