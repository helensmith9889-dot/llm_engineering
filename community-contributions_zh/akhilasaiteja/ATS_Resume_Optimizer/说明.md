# ATS 简历优化器

一款 AI 驱动的简历优化工具：对照职位描述（JD）给简历打分，用与 JD 对齐的词汇改写要点，并支持多轮对话精修简历。

---

## 功能

- 上传简历（PDF 或 DOCX）并粘贴职位描述
- 抽取 JD 关键词，用双层匹配引擎打分（精确匹配 + GPT 语义分析）
- 在经验支撑的前提下，改写要点以融入 JD 词汇
- 按关键词覆盖、相关经验、教育匹配计算加权 ATS 分数
- 区分缺失的硬技能与软技能——软技能不计入打分
- 通过交互式聊天精修简历；仅在用户确认有相关经验时才新增技能
- 下载优化后的 DOCX 与 PDF

---

## 技术栈

Python、GPT-4o、Gradio、Docker、Hugging Face Spaces、GitHub Actions

---

## 如何运行

```bash
pip install -r requirements.txt
echo "OPENAI_API_KEY=your_key_here" > .env
python app.py
```
