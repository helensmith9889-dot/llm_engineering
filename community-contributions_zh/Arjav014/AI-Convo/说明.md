# AI-Convo（三方 AI 对话）

一个交互式多智能体对话模拟：三个不同 AI 模型各自扮演独特性格角色，轮流发言，并引用完整聊天历史。

## 人设

1. **Alex**（愤怒且沮丧）：不耐烦、易恼火，爱用全大写和阴阳怪气的叹息。
2. **Blake**（冷静害羞）：轻声细语，常用犹豫词（`um...`、`uh...`），回避冲突。
3. **Charlie**（搞笑健谈）：高能量、爱讲笑话，喜欢双关语与流行文化梗。

## 技术栈与模型

*   **运行环境：** Jupyter Notebook（`main.ipynb`）
*   **API 客户端：** `openai` Python SDK（配置为 Groq API 端点）
*   **模型配置：**
    *   Alex: `openai/gpt-oss-120b`
    *   Blake: `llama-3.3-70b-versatile`
    *   Charlie: `groq/compound-mini`

## 安装与运行

1.  **进入项目目录**：
    ```bash
    cd community-contributions/Arjav014/AI-Convo
    ```

2.  **安装依赖**：
    ```bash
    pip install -r requirements.txt
    ```

3.  **环境变量**：
    在本目录创建 `.env` 并填入 API Key：
    ```env
    GROQ_API_KEY=your_groq_api_key_here
    ```

4.  **运行 Notebook**：
    在 VS Code 或 Jupyter 中打开 `main.ipynb`，按顺序执行单元格，即可观看三方对话（Markdown 展示）。
