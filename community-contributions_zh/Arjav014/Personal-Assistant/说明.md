# 集成 Google 日历的个人 AI 助手

基于 Gradio 的交互式个人助手，由 Groq API 驱动（OpenAI SDK 兼容）。助手带有自主智能体循环以处理工具调用，并专门集成了 **Google Calendar API**，可安排、列出与删除日历事件。

## 功能
- **人设**：精力旺盛、咖啡因过量的「死党」助手，回答极度简洁。
- **动态日期解析**：自动获取当前日期/时间，以理解「明天」「下周五」等相对时间。
- **Google 日历工具**：
  - 列出某一天或未来一周的事件
  - 创建事件并自动对齐时区偏移
  - 用 Google Calendar 事件 ID 删除事件
- **自主工具调用循环**：单轮用户请求中可触发多次工具调用。

## 前提与安装

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置环境变量
在项目根目录创建 `.env`：
```env
GROQ_API_KEY=your_groq_api_key_here
```

### 3. Google Calendar API 设置
1. 打开 [Google Cloud Console](https://console.cloud.google.com/)。
2. 新建或选择项目。
3. 启用 **Google Calendar API**。
4. 配置 **OAuth 同意屏幕**：
   - 用户类型设为 **External（外部）**
   - 在 **测试用户** 中添加你要连接的 Google 账号邮箱
5. 生成凭证：
   - **凭据** → **创建凭据** → **OAuth 客户端 ID**
   - 应用类型选 **桌面应用**
   - 下载 JSON，重命名为 `credentials.json` 并放到本目录

---

## 使用方法

1. 在 Jupyter（VS Code / JupyterLab 等）打开 `main.ipynb`。
2. 按顺序运行单元格。
3. 首次触发日历操作时，浏览器会弹出 Google 登录授权。
4. 授权后本地生成 `token.json`，之后无需再开浏览器。

---

## 安全警告

切勿把 `credentials.json` 或 `token.json` 提交到公开仓库（如 GitHub）。它们含有敏感认证信息与刷新令牌。本项目已通过 `.gitignore` 忽略这些文件。
