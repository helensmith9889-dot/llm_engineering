# 贝叶斯推断（Bayesian Inference）

**快速摘要（2–4 句）：**  
> 贝叶斯推断是一种统计推理方法：随着新证据出现，不断更新某个假设的概率。它基于贝叶斯定理，在先验信念与观测数据之间取得平衡。

**细微差别 / 注意点：**  
- 需要选择先验，先验可能带来偏差。  
- 对大型模型计算成本高。  
- 常用 MCMC 或变分方法做近似。  

**核心概念：**  
- **先验（Prior）：** 见到数据前的初始信念。  
- **似然（Likelihood）：** 在给定假设下数据出现的概率。  
- **后验（Posterior）：** 看到证据后更新的信念。  

**直观例子 / 演示：**  
> 若你认为一枚硬币公平（50/50），但它 10 次中有 8 次正面朝上，贝叶斯推断可让你更新信念：这枚硬币可能偏向正面。  

**何时有用 / 局限：**  
- 适用于机器学习、垃圾邮件过滤、A/B 测试等。  
- 局限：先验选得不好时可能误导结论。  

**简洁学习路径（4–7 步）：**  
1. 学习概率基础（Khan Academy，约 3 小时）。  
2. 用简单硬币/骰子例子学习贝叶斯定理。  
3. 阅读贝叶斯统计教材（Gelman 等）。  
4. 用 PyMC 在 Python 中实现简单模型（约 5 小时）。  

**练习（2–4，含难度）：**  
1. [简单] 在给定先验下计算硬币公平性的后验概率。  
2. [中等] 实现一个贝叶斯垃圾邮件过滤器。  

**参考与引用**  
1. Gelman A. *Bayesian Data Analysis* (2013).  
2. PyMC 文档 — https://www.pymc.io
