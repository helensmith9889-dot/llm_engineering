# 本地 Ollama 聊天机器人

基于终端的模块化聊天机器人，借助 [Ollama](https://ollama.com/) 在本地运行大语言模型（LLM）。  
支持流式回复、会话持久化、模型管理与性能统计。

## 功能

- 支持 **Windows** 与 **Linux/macOS**
- 自动检测已安装的 Ollama 模型
- 可选择要运行的本地模型
- 会停掉其他正在运行的 Ollama 模型以释放资源
- 实时流式输出回复
- 每次回复显示 token 用量与耗时统计

## 工作流程

1. 启动时清屏，并检查是否存在 `chat_context.json`
2. 若有历史会话，可选择加载
3. 从已安装模型列表中选择一个模型
4. 停止其他活跃模型以提升性能
5. 进入交互式对话循环，将回复流式打印到终端
6. 程序退出时自动停止当前模型

## 命令

聊天过程中可使用：

- `bye` → 退出聊天机器人
- `chat_context` → 显示当前对话历史
- `stats` → 显示本会话统计（token、生成耗时、平均速度等）

## 上下文持久化

使用 `chat_context.json` 在多次启动之间保存对话。

### 说明

- 启动时自动检测是否已有聊天记录
- 可选择是否继续上次会话
- 可先保存上下文，再换模型加载，从而用不同模型继续同一段对话
- 退出前会询问是否保存会话
- 以兼容 Ollama API 的标准 JSON 格式保存

## 前置条件

- 已安装并正在运行 Ollama
- Python 3.x
- Ollama Python 库

安装库：

```bash
pip install ollama
```
