# InterView-Coder 2.0

InterView-Coder 2.0 可直接从屏幕截取编程题目，用 OCR 提取文本，并用本地 LLM 生成优化后的解答。

## 功能

* 基于区域的屏幕截取，支持全局快捷键。
* 使用 Tesseract 进行 OCR，提取题目文本。
* 通过 Ollama 由 AI 生成解答：

  * 题目分析
  * 暴力解、改进解与最优解
  * 时间与空间复杂度
  * JavaScript 实现
* 最终解答自动复制到剪贴板。

## 快捷键

| 快捷键             | 动作                                      |
| ------------------ | ------------------------------------------- |
| `Ctrl + Shift + S` | 设置截取区域左上角                 |
| `Ctrl + Shift + D` | 设置截取区域右下角             |
| `Ctrl + Shift + A` | 运行 截取 → OCR → AI → 剪贴板 流水线 |

## 安装

### 前置条件

```bash
brew install tesseract
```

安装 Ollama 并拉取所需模型：

```bash
ollama pull gemma4:latest
```

### 设置

```bash
git clone <repo-url>
cd <repo-name>

pip install -r requirements.txt
# 或者
uv sync
```

如有需要，请在 `ocr/reader.py` 中更新 Tesseract 路径。

## 项目结构

```text
ai/        AI 提示与 Ollama 集成
capture/   屏幕截取与区域选择
ocr/       OCR 处理
ui/        弹窗界面
utils/     工具函数
temp/      临时截图
main.py    应用入口
```
