# 网站宣传册生成器

一款 AI 工具：从任意网站自动生成专业宣传册。工具会分析网站内容、提取相关信息，并用 OpenAI GPT 模型生成排版良好的宣传册。

## 功能

- 🌐 **网站分析**：自动抓取并分析网站内容
- 🤖 **AI 驱动**：使用 OpenAI GPT-4o-mini 智能生成内容
- 📄 **专业输出**：生成 Markdown 格式宣传册
- 🌍 **多语言支持**：用 AI 将宣传册翻译成任意语言
- 🎨 **美观输出**：Rich 终端排版与 Jupyter 原生 Markdown 渲染
- ⚡ **流式支持**：实时生成并更新
- 🖥️ **多种界面**：命令行脚本与交互式 Jupyter notebook
- 📓 **交互 Notebook**：分步执行，含控件与示例

## 前置条件

- Python 3.8 或更高
- OpenAI API 密钥
- Jupyter notebook 环境（若使用 notebook）

## 安装

### 方案 1：使用 uv（推荐）

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
cd Website_brochure_generator
uv sync
source .venv/bin/activate  # Windows: .venv\Scripts\activate
```

### 方案 2：使用 pip

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## 配置

1. 在 [OpenAI API Keys](https://platform.openai.com/api-keys) 创建密钥
2. 在项目目录创建 `.env`：
   ```bash
   OPENAI_API_KEY=your_api_key_here
   ```

## 用法

### Jupyter Notebook（推荐交互使用）

```bash
jupyter notebook 网站宣传册生成器.ipynb
# 或原文 website_brochure_generator.ipynb
```

逐步运行单元格：配置 API 密钥、试用交互示例、用控件轻松生成宣传册。

### 命令行

```bash
python website_brochure_generator.py https://example.com
# 将提示选择：完整输出或流式输出；是否翻译
```

### Python 调用

```python
from website_brochure_generator import create_brochure, stream_brochure, translate_brochure

result = create_brochure("https://example.com")
result = stream_brochure("https://example.com")
spanish_brochure = translate_brochure("https://example.com", "Spanish", stream_mode=False)
```

## 工作原理

1. **网站抓取**：提取标题、内容、链接，并清洗文本
2. **链接分析**：用 AI 识别 About、公司信息、招聘、新闻等页面
3. **内容聚合**：抓取相关页面并合并
4. **宣传册生成**：用 GPT-4o-mini 生成公司概览、产品/服务、文化、职业机会、联系方式等
5. **翻译（可选）**：保持 Markdown 格式与专业语气，保留专有名词

## 依赖

- `openai`、`python-dotenv`、`requests`、`beautifulsoup4`、`rich`、`ipywidgets`

## 故障排除

1. **缺少 rich**：`pip install -r requirements.txt`
2. **API Key 错误**：检查 `.env` 与额度
3. **抓取被拦**：部分站点会拦截自动化请求；工具已使用标准 User-Agent
4. **显示问题**：CLI 需 Rich；Jupyter 需 ipywidgets
