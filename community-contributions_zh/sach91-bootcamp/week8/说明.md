# KnowledgeHub — 个人知识管理与研究助手

优雅、完全本地运行的 AI 知识管理系统：用前沿 LLM 技术帮助你组织、检索并理解文档。

## 功能

### 核心能力
- **文档入库**：上传 PDF、DOCX、TXT、MD、HTML
- **智能问答**：基于 RAG，针对你的文档提问并获得答案
- **智能摘要**：生成含要点的精炼摘要
- **关联发现**：发现文档之间的关系
- **多格式导出**：导出为 Markdown、HTML 或纯文本
- **统计仪表盘**：追踪知识库增长

### 隐私优先
- **100% 本地处理**：数据留在你的机器上
- **无云依赖**：使用 Ollama 做本地 LLM 推理
- **开源**：完全透明可控

### 技术栈
- **LLM**：Ollama + Llama 3.2（3B）或 Llama 3.1（8B）
- **Embeddings**：sentence-transformers（all-MiniLM-L6-v2）
- **向量库**：ChromaDB
- **UI**：Gradio
- **文档处理**：pypdf、python-docx、beautifulsoup4

## 快速开始

### 前置条件

1. 已安装 **Python 3.8+**
2. 已安装并运行 **Ollama**

#### 安装 Ollama

**macOS/Linux：**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

**Windows：**
从 [ollama.com/download](https://ollama.com/download) 下载

### 安装

1. **克隆或下载本仓库**

2. **安装 Python 依赖：**
```bash
pip install -r requirements.txt
```

3. **用 Ollama 拉取 Llama 模型：**
```bash
# 更快推理（多数用户推荐）
ollama pull llama3.2

# 或更高质量（需要更多 RAM）
ollama pull llama3.1
```

4. **启动 Ollama 服务**（若尚未运行）：
```bash
ollama serve
```

5. **启动 KnowledgeHub：**
```bash
python app.py
```

应用将在浏览器打开：`http://127.0.0.1:7860`

## 使用指南

### 1. 上传文档
- 进入 “Upload Documents” 标签
- 选择文件（PDF、DOCX、TXT、MD 或 HTML）
- 点击 “Upload & Process”
- 文档将被分块并存入本地向量库

### 2. 提问
- 进入 “Ask Questions” 标签
- 用自然语言输入问题
- 调整检索来源数量（默认 5）
- 点击 “Ask” 获取带来源的 AI 答案

### 3. 摘要文档
- 进入 “Summarize” 标签
- 从下拉框选择文档
- 点击 “Generate Summary”
- 获得含要点的精炼摘要

### 4. 发现关联
- 进入 “Find Connections” 标签
- 选择要分析的文档
- 调整要找的相关文档数量
- 查看语义相似的文档

### 5. 导出知识
- 进入 “Export” 标签
- 选择格式（Markdown、HTML 或 Text）
- 点击 “Export” 下载知识库

### 6. 查看统计
- 进入 “Statistics” 标签
- 查看知识库概览
- 追踪文档、分块与字符总数

## 多智能体框架

KnowledgeHub 使用精巧的多智能体架构：

1. **Ingestion Agent**：解析文档、分块、生成嵌入
2. **Question Agent**：检索相关上下文并回答问题
3. **Summary Agent**：生成精炼摘要并提取要点
4. **Connection Agent**：发现文档间语义关系
5. **Export Agent**：以多种格式整理并导出知识

每个智能体独立、可复用、专注单一任务，符合智能体式 AI 开发最佳实践。

## 配置

### 更换模型

编辑 `app.py` 使用不同模型：

```python
# Llama 3.1 8B（质量更好，更占 RAM）
self.llm_client = OllamaClient(model="llama3.1")

# Llama 3.2 3B（更快，更省 RAM）
self.llm_client = OllamaClient(model="llama3.2")
```

### 调整分块大小

编辑 `agents/ingestion_agent.py`：

```python
self.parser = DocumentParser(
    chunk_size=1000,      # 每块字符数
    chunk_overlap=200     # 块间重叠
)
```

### 更换嵌入模型

编辑 `app.py`：

```python
self.embedding_model = EmbeddingModel(
    model_name="sentence-transformers/all-MiniLM-L6-v2"
)
```

## 故障排查

### “Cannot connect to Ollama”
- 确认已安装：`ollama --version`
- 启动服务：`ollama serve`
- 确认已拉取模型：`ollama list`

### “Module not found” 错误
- 安装全部依赖：`pip install -r requirements.txt`
- 尝试升级 pip：`pip install --upgrade pip`

### “Out of memory” 错误
- 改用 Llama 3.2（3B）而非 Llama 3.1（8B）
- 减小文档解析器的 chunk_size
- 一次处理更少文档

### 响应缓慢
- 如有条件使用支持 CUDA 的 GPU
- 减少检索块数量（top_k）
- 使用更小模型（llama3.2）

## 性能

**硬件要求：**
- 最低：8GB RAM，CPU
- 推荐：16GB RAM，GPU（NVIDIA + CUDA）
- 更佳：32GB RAM，GPU（RTX 3060 或更好）

**处理速度**（M1 Mac 上 Llama 3.2）：
- 文档入库：约每页 2–5 秒
- 问答：约 5–15 秒
- 摘要：约 10–20 秒
