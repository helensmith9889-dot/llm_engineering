分号¶
与 C 一样，Go 的形式文法用分号终止语句；但与 C 不同，这些分号通常不出现在源码里。词法分析器在扫描时用简单规则自动插入分号，因此输入文本大多看不到分号。

规则是：若换行前的最后一个记号是标识符（包括 `int`、`float64` 这类词）、基本字面量（数字或字符串常量），或下列记号之一：

```
break continue fallthrough return ++ -- ) }
```

词法分析器总会在该记号后插入分号。可概括为：「若换行出现在可能结束语句的记号之后，就插入分号」。

在闭花括号前也可以省略分号，因此像下面这样的语句：

```go
    go func() { for { dst <- <-src } }()
```

不需要分号。地道的 Go 程序通常只在 `for` 循环子句等处使用分号，以分隔初始化、条件与后续部分；若把多条语句写在同一行，也需要分号分隔。

分号插入规则的一个后果是：不能把控制结构（`if`、`for`、`switch` 或 `select`）的开花括号放到下一行。否则会在花括号前插入分号，可能造成意外效果。应这样写：

```go
if i < f() {
    g()
}
```

而不是：

```go
if i < f()  // wrong!
{           // wrong!
    g()
}
```

控制结构¶
Go 的控制结构与 C 相关，但有重要差异。没有 `do` 或 `while` 循环，只有略加泛化的 `for`；`switch` 更灵活；`if` 与 `switch` 可像 `for` 一样接受可选初始化语句；`break` 与 `continue` 可带可选标签；还有类型 switch、以及多路通信复用器 `select` 等新结构。语法也略有不同：没有括号，且主体必须用花括号界定。

If¶
Go 中简单的 `if` 如下：

```go
if x > 0 {
    return y
}
```

强制花括号鼓励把简单 `if` 写成多行。这本来就是好风格，尤其当主体含 `return` 或 `break` 等控制语句时。

由于 `if` 与 `switch` 接受初始化语句，常见用法是用来设置局部变量：

```go
if err := file.Chmod(0664); err != nil {
    log.Print(err)
    return err
}
```

在 Go 库中你会发现：当 `if` 不会流入下一条语句——也就是主体以 `break`、`continue`、`goto` 或 `return` 结束——时，会省略不必要的 `else`。

```go
f, err := os.Open(name)
if err != nil {
    return err
}
codeUsing(f)
```

这是必须防范一连串错误条件时的常见写法。若成功控制流顺着页面向下推进、出错则当场排除，代码会很好读。由于错误分支往往以 `return` 结束，结果代码不需要 `else`。

```go
f, err := os.Open(name)
if err != nil {
    return err
}
d, err := f.Stat()
if err != nil {
    f.Close()
    return err
}
codeUsing(f, d)
```

重新声明与重新赋值¶
旁白：上一节最后的例子展示了 `:=` 短变量声明的一个细节。调用 `os.Open` 的声明是：

```go
f, err := os.Open(name)
```

它声明了两个变量 `f` 与 `err`。几行后，`f.Stat` 调用是：

```go
d, err := f.Stat()
```

看起来像又声明了 `d` 与 `err`。但注意 `err` 出现在两条语句中。这种重复是合法的：`err` 由第一条语句声明，在第二条中只是重新赋值。也就是说，`f.Stat` 使用的是上面已声明的 `err`，只是赋了新值。

在 `:=` 声明中，变量 `v` 即便已经声明也可以再次出现，前提是：

- 该声明与 `v` 的既存声明处于同一作用域（若 `v` 已在外层作用域声明，则会创建新变量 §）；
- 初始化中的对应值可赋给 `v`；
- 该声明至少还创建了另一个新变量。

这一不寻常特性纯属实用主义，例如便于在长 `if-else` 链中复用同一个 `err`。你会经常看到它。

§ 值得指出：在 Go 中，函数参数与返回值的作用域与函数体相同，尽管它们在词法上写在包围函数体的花括号之外。

For¶
Go 的 `for` 循环与 C 相似但不同。它统一了 `for` 与 `while`，且没有 `do-while`。有三种形式，只有一种带分号。

```go
// 类似 C 的 for
for init; condition; post { }

// 类似 C 的 while
for condition { }

// 类似 C 的 for(;;)
for { }
```

短声明便于在循环里直接声明索引变量。

```go
sum := 0
for i := 0; i < 10; i++ {
    sum += i
}
```

若遍历数组、切片、字符串、map，或从 channel 读取，可用 `range` 子句管理循环。

```go
for key, value := range oldMap {
    newMap[key] = value
}
```

若只需要 range 的第一项（键或下标），丢掉第二项：

```go
for key := range m {
    if key.expired() {
        delete(m, key)
    }
}
```

若只需要第二项（值），用空白标识符 `_` 丢弃第一项：

```go
sum := 0
for _, value := range array {
    sum += value
}
```

空白标识符还有许多用途，见后文。

对字符串，`range` 会多做一步：解析 UTF-8 并拆出各个 Unicode 码点。错误编码会消耗一字节并产生替换符 `U+FFFD`。（`rune` 及其内建类型是 Go 对单个 Unicode 码点的术语，详见语言规范。）循环：

```go
for pos, char := range "日本\x80語" { // \x80 是非法 UTF-8 编码
    fmt.Printf("character %#U starts at byte position %d\n", char, pos)
}
```

打印：

```
character U+65E5 '日' starts at byte position 0
character U+672C '本' starts at byte position 3
character U+FFFD '�' starts at byte position 6
character U+8A9E '語' starts at byte position 7
```

最后，Go 没有逗号运算符，`++` 与 `--` 是语句而非表达式。因此若要在 `for` 中驱动多个变量，应使用并行赋值（但这排除了 `++`/`--`）。

```go
// 反转 a
for i, j := 0, len(a)-1; i < j; i, j = i+1, j-1 {
    a[i], a[j] = a[j], a[i]
}
```

Switch¶
Go 的 `switch` 比 C 更通用。表达式不必是常量甚至整数；`case` 从上到下求值直到匹配；若 `switch` 没有表达式，则相当于对 `true` 做 switch。因此可以把 `if-else-if-else` 链写成 `switch`，这也很地道。

```go
func unhex(c byte) byte {
    switch {
    case '0' <= c && c <= '9':
        return c - '0'
    case 'a' <= c && c <= 'f':
        return c - 'a' + 10
    case 'A' <= c && c <= 'F':
        return c - 'A' + 10
    }
    return 0
}
```

没有自动贯穿（fall through），但可用逗号分隔列表写出多个 case。

```go
func shouldEscape(c byte) bool {
    switch c {
    case ' ', '?', '&', '=', '#', '+', '%':
        return true
    }
    return false
}
```

尽管在 Go 中不如某些类 C 语言常见，仍可用 `break` 提前结束 `switch`。有时需要跳出的是外层循环而非 `switch`，这时可给循环加标签并 `break` 到该标签。下例展示两种用法。

```go
Loop:
    for n := 0; n < len(src); n += size {
        switch {
        case src[n] < sizeOne:
            if validateOnly {
                break
            }
            size = 1
            update(src[n])

        case src[n] < sizeTwo:
            if n+1 >= len(src) {
                err = errShortInput
                break Loop
            }
            if validateOnly {
                break
            }
            size = 2
            update(src[n] + src[n+1]<<shift)
        }
    }
```

当然，`continue` 也可带可选标签，但只作用于循环。

本节收尾：用两个 `switch` 比较字节切片的例程：

```go
// Compare 按字典序比较两个字节切片，返回整数。
// a == b 返回 0；a < b 返回 -1；a > b 返回 +1
func Compare(a, b []byte) int {
    for i := 0; i < len(a) && i < len(b); i++ {
        switch {
        case a[i] > b[i]:
            return 1
        case a[i] < b[i]:
            return -1
        }
    }
    switch {
    case len(a) > len(b):
        return 1
    case len(a) < len(b):
        return -1
    }
    return 0
}
```

类型 switch¶
`switch` 也可用来发现接口变量的动态类型。这种类型 switch 使用类型断言语法，并在括号中写关键字 `type`。若 switch 在表达式中声明变量，则该变量在每个子句中具有对应类型。在这类情形下复用同名也很地道——实际上是在每个 case 中声明同名但不同类型的新变量。

```go
var t interface{}
t = functionOfSomeType()
switch t := t.(type) {
default:
    fmt.Printf("unexpected type %T\n", t)     // %T 打印 t 的实际类型
case bool:
    fmt.Printf("boolean %t\n", t)             // t 类型为 bool
case int:
    fmt.Printf("integer %d\n", t)             // t 类型为 int
case *bool:
    fmt.Printf("pointer to boolean %t\n", *t) // t 类型为 *bool
case *int:
    fmt.Printf("pointer to integer %d\n", *t) // t 类型为 *int
}
```
