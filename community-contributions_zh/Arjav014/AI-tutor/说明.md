# AI 导师

一个交互式、偏教育向且带点幽默的 AI 导师（Jupyter Notebook 实现）。通过 Gemini API（经 OpenAI Python 客户端）回答编程、计算机科学、数学与软件工程问题，并用类比与轻笑话增强讲解。

## 功能
- **有趣的 AI 人设：** 把复杂技术讲清楚，善用幽默、类比与贴近生活的例子。
- **Markdown 输出：** 结构化标题、列表、代码块与表格。
- **实时流式：** 逐块流式返回，学习体验更跟手。
- **OpenAI 客户端集成：** 用标准 `openai` 库对接 Gemini 的 OpenAI 兼容端点。

---

## 前提条件
- **Python 3.12+**
- **Gemini API Key：** 从 [Google AI Studio](https://aistudio.google.com/) 获取。
- **uv：** 快速的 Python 包安装/解析工具。

---

## 安装步骤

### 1. 进入目录
```bash
cd community-contributions/Arjav014/AI-tutor
```

### 2. 配置环境变量
在 `AI-tutor` 目录创建 `.env`：
```bash
GOOGLE_API_KEY=your_gemini_api_key_here
```

---

## 用 `uv` 运行

### 方法 1：直接跑 Jupyter（零配置）
```bash
uv run --with jupyter -r requirements.txt jupyter notebook main.ipynb
```

### 方法 2：标准虚拟环境
```bash
uv venv
source .venv/bin/activate
uv pip install -r requirements.txt
jupyter notebook main.ipynb
```

---

## 项目结构
- `main.ipynb`：主交互 Notebook
- `requirements.txt`：Python 依赖
- `requirements.md`：依赖与环境说明
