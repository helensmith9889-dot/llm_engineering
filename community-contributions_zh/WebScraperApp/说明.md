# 网页抓取和数据分析器

具有时尚 PyQt5 GUI 的现代 Python 应用程序，用于网络抓取、数据分析、可视化和人工智能驱动的网站洞察。具有简洁、简约的设计，具有实时进度跟踪、全面的数据过滤以及用于高级分析的集成人工智能聊天助手。

## 特征

- **现代用户界面**：干净、简约的设计，带有深色主题和流畅的动画
- **网页抓取**：具有可配置深度的多线程抓取（最多 100 个级别）
- **数据可视化**：具有排序和过滤功能的交互式表格
- **内容预览**：具有文本和视觉 HTML 渲染的双预览系统
- **数据分析**：综合统计和领域细分
- **人工智能分析**：基于聊天的助手，用于网站洞察、SEO 建议和内容分析
- **导出功能**：带有完整元数据的 JSON 导出
- **URL 规范化**：智能处理 www/非 www 域
- **实时进度**：抓取操作期间的实时进度更新
- **循环预防**：高级重复检测以防止无限循环
- **智能限制**：可配置限制以防止失控抓取

## AI 分析选项卡

该应用程序具有高级 **AI 分析** 选项卡：

- **对话式聊天 UI**：在现代聊天界面（如 ChatGPT）中询问有关您抓取的网站的问题
- **快速操作**：关于结构、SEO、内容主题和性能的一键式问题
- **Markdown 回复**：AI 回复的格式清晰易读
- **情境感知**：人工智能使用您抓取的数据来获得量身定制的见解
- **要求**：互联网连接和 `openai` Python 包（请参阅安装）
- **后备**：如果未安装“openai”，则会显示占位符响应

## 循环预防和重复检测

该刮刀具有针对无限循环和循环引用的强大保护：

### 🔄 URL 规范化
- 删除“www.”前缀以实现一致的域处理
- 去除 URL 片段（`#section`）以防止重复内容
- 删除尾部斜杠以保持一致性
- 标准化查询参数

### 🚫 重复检测
- **访问过的 URL 跟踪**：维护一组所有访问过的 URL
- **无限抓取**：每个域或总页数没有页面限制
- **每页重复过滤**：删除同一页面内的重复链接

### 🛡️ 智能限制
- **无深度限制**：爬行指定 max_深度允许的深度
- **内容类型过滤**：仅抓取 HTML 内容
- **文件类型过滤**：跳过非内容文件（PDF、图像等）
- **连续空关检测**：如果连续3个关卡没有新内容则停止

### 📊 增强跟踪
- **域名页面计数**：跟踪每个域抓取的页面（用于统计）
- **URL 检查计数**：显示检查的 URL 总数与抓取的页面数
- **详细统计**：关于抓取效率的综合报告
- **无限处理**：对抓取范围没有人为限制

## 安装

1. **克隆或下载项目文件**

2. **安装依赖**：
   ```bash
   pip install -r requirements.txt
   ```
   - 这将安装所有必需的软件包，包括“PyQt5”、“PyQtWebEngine”（用于视觉预览）和“openai”（用于 AI 功能）。

3. **运行应用程序**：
   ```bash
   python web_scraper_app.py
   ```

## 用法

### 1. 抓取配置
- 输入起始 URL（带或不带 http/https）
- 设置最大爬行深度（1-100）
- 单击“开始抓取”开始

### 2. 数据查看和过滤
- 在交互式表格中查看抓取的数据
- 按搜索词或特定域过滤
- 双击任意行预览内容
- 将数据导出为JSON格式

### 3. 分析与统计
- 查看全面的抓取统计数据
- 查看域名细分和字数统计
- 以文本和视觉格式预览内容
- 分析加载时间和链接计数
- 监控重复检测效率

### 4.人工智能分析（新！）
- 切换到**AI分析**选项卡
- 输入您的问题或使用快速操作按钮（例如，“分析网站结构”、“建议 SEO 改进”）
- 人工智能将分析您抓取的数据并提供可行的见解
- 需要互联网连接和“openai”包

## 视觉预览功能

该应用程序包括可视化 HTML 预览功能，可以在类似浏览器的视图中呈现抓取的网页：

- **要求**：PyQtWebEngine（随requirements.txt自动安装）
- **功能**：以正确的样式和格式显示 HTML 内容
- **后备**：如果 PyQtWebEngine 不可用，则显示纯文本预览

- **线程**：多线程抓取以获得更好的性能
- **数据存储**：具有完整元数据的网站对象
- **URL处理**：智能规范化和域过滤
- **循环预防**：多层重复检测系统

## 故障排除

### 视觉预览不起作用
1. 确保 PyQtWebEngine 已安装：`pip install PyQtWebEngine`
2. 检查控制台输出是否存在导入错误

### 人工智能分析不起作用
1. 确保安装了`openai`包：`pip install openai`
2.检查您的互联网连接（AI需要在线访问）
3. 如果未安装，AI选项卡将显示占位符响应

### Scraping Issues
1. Verify internet connection
2. Check URL format (add https:// if needed)
3. Try with a lower depth setting
4. Check console for error messages

### 循环预防
1. 刮刀自动防止无限循环
2.查看分析选项卡进行详细统计
3. 监控“检查的 URL 总数”与“页面总数”以提高效率
4.对于有很多内部链接的网站使用较低的深度设置

### 性能
- 使用较低的深度设置以加快刮擦速度
- 过滤数据以关注特定领域
- 关闭其他应用程序以释放资源
- 监控域页面计数以避免达到限制
