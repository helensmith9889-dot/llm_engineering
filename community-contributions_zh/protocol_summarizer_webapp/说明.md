# 临床试验方案摘要 Web 应用

基于 Streamlit 的 Web 应用，用于从 ClinicalTrials.gov 搜索临床试验方案，并用大语言模型做摘要。帮助研究者与临床专业人员快速提取方案关键信息。

## 功能
- 按关键词搜索临床试验
- 展示含标题与 NCT 编号的研究列表
- 选择一项研究进行摘要
- 从 ClinicalTrials.gov API 拉取方案简要说明
- 使用 OpenAI LLM 自动摘要方案
- 提取研究设计、人群、干预措施、终点等结构化信息

## 安装

1. 克隆本仓库：
   ```sh
   git clone https://github.com/albertoclemente/protocol_summarizer.git
   cd protocol_summarizer/protocol_summarizer_webapp
   ```

2. 安装依赖：
   ```sh
   pip install -r requirements.txt
   ```

3. 在项目根目录创建 `.env`，写入 OpenAI API 密钥：
   ```
   OPENAI_API_KEY=your_api_key_here
   ```

## 用法

1. 运行 Streamlit 应用：
   ```sh
   streamlit run app.py
   ```

2. 在浏览器中：
   - 在搜索框输入疾病、病况或关键词
   - 选择要显示的结果数量
   - 点击 “Search”
   - 从结果中选择一项研究
   - 点击 “Summarize Protocol” 生成结构化摘要

## 技术细节

- 使用 ClinicalTrials.gov API v2 检索研究信息
- 实现回退方法以应对 API 变更或失败
- 通过可靠的 JSON 解析提取方案简要说明
- 使用 OpenAI GPT 模型生成结构化摘要

## 环境要求

- Python 3.7+
- Streamlit
- Requests
- OpenAI Python 库
- python-dotenv
