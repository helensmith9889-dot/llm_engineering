# 文档问答代理

本地人工智能代理可以读取文档（PDF、DOCX、TXT）并让您用简单的英语提出有关它们的问题 - 所有这些都在您自己的计算机上私下运行。

## 先决条件

1. **Ollama** 安装并运行 — [ollama.com](https://ollama.com)
2. **llama3.2** 模型拉取：```bash
   ollama pull llama3.2
   ```3. **uv** 安装：```bash
   curl -Ls https://astral.sh/uv/install.sh | sh
   ```## 如何运行

打开终端，导航到该文件夹，然后运行：```bash
uv run agent.py
```代理将询问您文件路径，然后您可以开始询问有关该文档的问题。

## 支持的文件类型

|格式|扩展|
|--------|------------|
| PDF | `.pdf` |
|词| `.docx` |
|文字| `.txt` |

## 项目结构```
document_qa_agent/
├── agent.py             ← Main chat loop
├── llm.py               ← LLM communication
├── config.py            ← Model settings & system prompt
└── transcript_parser.py ← Document reading
```
