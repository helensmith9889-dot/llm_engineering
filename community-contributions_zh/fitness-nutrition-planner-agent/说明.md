# 健身和营养规划代理（社区贡献）

一种使用工具的代理，可生成**7天素食友好膳食计划**，其中包含**卡路里/宏观目标**和**综合杂货清单**。它支持**有针对性的交换**（例如，“交换星期二午餐”），同时尊重饮食模式、过敏和不喜欢的东西。

> **免责声明**：该项目用于教育目的，**不是**医疗建议。如有医疗或特殊饮食需求，请咨询有执照的专业人士。

---

## ✨ 特点
- 通过 Mifflin–St Jeor + 活动因子计算 **TDEE** 和 **宏观目标**。
- 制定一个尊重饮食限制的**7 天计划**（早餐/午餐/晚餐）。
- 生成本周的汇总**杂货清单**。
- 支持任何单餐的**交换**，同时保持宏合理。
- 用于演示的最小 **Streamlit UI**。
- 可扩展的**基于工具的架构**，可插入真实的配方 API/数据库。

---

## 🧱 架构
- **代理核心**：具有简单编排循环的 OpenAI 函数调用（工具）。
- **工具**：
  1. `calc_calories_and_macros` – 计算目标。
  2. `compose_meal_plan` – 创建 7 天计划。
  3. `grocery_list_from_plan` – 合并成分/数量。
  4. `swap_meal` – 代替一顿饭（根据千卡接近度和限制）。
- **菜谱源**：用于演示的小型内存菜谱数据库；替换为真实的 API 或您自己的数据集。

## 🚀 快速入门

### 1) 安装```bash
pip install openai streamlit pydantic python-dotenv
```### 2) 配置
在此文件夹中创建一个“.env”文件：```
OPENAI_API_KEY=your_key_here
OPENAI_MODEL=gpt-4o-mini
```### 3) 运行 CLI（示例）```bash
python agent.py
```### 4) 运行用户界面```bash
streamlit run app.py
```---

## 🔧 延长
- 将内存中的配方替换为：
  - 真正的 **recipe API**（例如 Spoonaulous）或
  - 您的**自己的数据集** (CSV/DB) + 过滤器/标签
- 添加价格查询以生成**预算意识**杂货清单。
- 添加**依从性跟踪**和图表。
- 集成**可穿戴设备**或日常步骤以动态优化 TDEE。
- 在略低于目标千卡的几天内添加**零食**。

---

## 🛡️ 安全注意事项
- 该代理会警告极度缺乏，但**不**诊断病情。
- 对于低于通常建议的最低热量（例如，许多成年人每天约 1200 kcal）的卡路里目标，建议咨询专业人士。
