# 与 SafeHaven Property Insurance 就 Homellm 签订的合同

**合同日期：** 2025 年 5 月 3 日
**合同编号：** HM-2025-E-0112
**当事方：**
- Insurellm, Inc.
- SafeHaven Property Insurance, Inc.

---

## 条款

1. **覆盖范围：** Insurellm 同意向 SafeHaven Property Insurance 提供 Homellm 平台的企业级访问权限，包括白标能力、无限保单、专用基础设施及全面物联网集成，以支持其财产保险运营。

2. **期限：** 本协议自合同日期起有效期为 36 个月。

3. **付款：** SafeHaven Property Insurance 应按定制企业版定价支付：第 1–12 个月每月 22,000 美元，第 13–24 个月每月 24,000 美元，第 25–36 个月每月 26,000 美元，合同期内合计 864,000 美元。

4. **保单量**：企业版支持无限保单。SafeHaven 目前在 6 个州拥有 45,000 份有效房主保单。

5. **服务水平协议：** Insurellm 保证按月计量平台正常运行时间达 99.9%；每低于目标 0.1% 给予当月费用 7% 的抵扣，最高每月抵扣 35%。

6. **保密：** 双方同意对专有算法、财产数据、定价模型及业务战略严格保密。

7. **数据安全：** Insurellm 维持 SOC 2 Type II 合规、ISO 27001 认证，并接受年度第三方安全审计。

---

## 续约

本协议包含 90 天双方续约通知期。SafeHaven 获得最惠客户定价及新功能优先访问权，包括气候风险建模与物联网创新。

---

## 功能

SafeHaven Property Insurance 将获得完整的 Homellm 企业版套件：

1. **无限保单管理：** 全面支持 SafeHaven 超过 45,000 份保单，并可随业务扩展至 200,000 份以上。

2. **白标平台：** 完整品牌定制：
   - 自定义域名（quote.safehavenproperty.com、myhome.safehavenproperty.com）
   - 带定制 UI 的 iOS 与 Android 品牌移动应用
   - 定制投保人沟通
   - 联合品牌代理人与经纪人门户

3. **高级 AI 风险评估：** 企业级财产风险分析：
   - 航拍影像分析，评估屋顶状况、植被与危险因素
   - 财产特征评估（房龄、结构、面积）
   - 基于位置的风险评分（野火、洪水、冰雹、风灾、地震）
   - 巨灾建模集成（RMS、AIR、CoreLogic）
   - 含通胀趋势的重置成本估算
   - 社区风险评估
   - 跨所有保险公司的理赔历史分析
   - 基于信用的保险评分

4. **动态定价模型：** 精密定价引擎：
   - 跨 200 多个费率变量的实时费率优化
   - 竞争情报与市场定位
   - 基于承保能力的动态定价
   - 多保单捆绑折扣
   - 忠诚度与保龄抵扣
   - 无赔款折扣自动化
   - 车联网与物联网折扣

5. **即时理赔处理：** 高级理赔自动化：
   - AI 驱动首次损失通知，支持照片/视频上传
   - 计算机视觉损失评估
   - 自动维修费用估算
   - 与超过 2,000 家供应商的承包商网络集成
   - 理赔路由与指派
   - 支持多方拆分的付款自动化
   - 含模式分析的欺诈检测
   - 代位求偿机会识别

6. **预测性维护提醒：** 物联网驱动的风险预防：
   - 与智能家居设备集成（漏水传感器、烟雾探测器、安防系统）
   - 天气预警系统，含风暴前通知
   - 冰冻预警与管道爆裂预防
   - 屋顶老化监控
   - HVAC 与家电故障预测
   - 野火邻近预警
   - 主动投保人沟通以预防损失

7. **多渠道集成：** 统一平台：
   - 面向超过 1,500 名独立代理人的代理人门户
   - 直接面向消费者的报价引擎
   - 含联合品牌的经纪人门户
   - 呼叫中心集成
   - 网页与移动应用报价
   - 智能家居设备连接

8. **客户门户：** 全面自助服务：
   - 24/7 保单访问与文件检索
   - 保障变更请求
   - 数字保险卡
   - 理赔提交与追踪
   - 付款处理与账单历史
   - 智能家居设备管理
   - 维护提醒与家居护理建议
   - 灾害准备资源

9. **物联网设备集成：** 智能家居平台：
   - 漏水检测系统（Flo by Moen、Phyn、LeakSmart）
   - 智能烟雾与一氧化碳探测器（Nest Protect、First Alert）
   - 安防系统（Ring、SimpliSafe、ADT）
   - 智能恒温器（Nest、Ecobee）
   - 气象站
   - 屋顶监控传感器
   - 物联网采用保费折扣（最高 20%）
   - 实时预警与干预协议

10. **完整 API 访问：** 无限 API 调用：
    - 与 SafeHaven 核心系统集成
    - 第三方数据提供商（CoreLogic、Verisk、LexisNexis）
    - 巨灾建模系统
    - 代理人管理平台
    - 支付处理商
    - 文档管理系统
    - 营销自动化

11. **多州运营：** 全面支持：
    - 全部 6 个州的州特定表格与批单
    - 监管合规监控
    - 费率与表格备案管理
    - 多州执照追踪
    - 按州的巨灾响应协议

12. **巨灾管理：** 灾害响应工具：
    - 巨灾前建模与风险敞口管理
    - 实时风暴追踪与影响评估
    - 巨灾理赔分诊与路由
    - 移动理赔团队调度
    - 供应商应急产能启动
    - 投保人沟通活动
    - 紧急付款处理

## 支持

Insurellm 承诺为 SafeHaven Property Insurance 提供全面的企业级支持：

1. **专属成功团队：**
   - 副总裁级高管赞助人，进行季度战略回顾
   - 高级客户成功经理，每两周一次沟通
   - 技术客户经理，负责系统优化
   - 解决方案架构师，负责物联网与创新项目
   - 含详细指标的季度高管业务回顾

2. **24/7/365 高级支持：**
   - P1 关键问题 20 分钟响应时间
   - P2 高优先级问题 1 小时响应
   - P3 标准问题 4 小时响应
   - 熟悉 SafeHaven 运营的专属支持团队
   - 可访问工程团队的私有 Slack 频道
   - 紧急巨灾响应团队（灾害期间 15 分钟响应）
   - 季度现场访问（每年至少 4 次）

3. **全面实施：**
   - 8 个月分阶段实施计划
   - 专属项目经理与 PMO
   - 从遗留系统迁移 45,000 份保单
   - 为 60 多名员工提供培训
   - 为 200 多名顶尖代理人提供代理人培训计划
   - 并行处理 90 天
   - 上线支持，现场驻场 6 周

4. **培训与赋能：**
   - 全面基于角色的培训计划
   - 核保人 AI 风险评估认证
   - 理赔员计算机视觉工具培训
   - 客服代表物联网设备培训

   - 月度高级培训网络研讨会
   - 无限在线学习平台访问

5. **定制开发：**
   - 每年 1,200 小时定制开发
   - 针对 SafeHaven 特定功能的专属开发资源
   - 优先功能请求，纳入路线图
   - 新功能正式发布前 60 天 Beta 访问
   - 智能家居与物联网联合创新项目

     - Applied Epic 代理机构管理
     - Guidewire ClaimCenter
     - 物联网平台（Nationwide Canopy、Ting 及其他）
     - 巨灾建模（RMS RiskLink）
     - 支付处理商
     - Salesforce CRM
   - 专属集成工程师（40% 全职人力）
   - 季度集成健康评估
