# 社区贡献：基于异步 Playwright 的 OpenAI 页面爬虫

本贡献展示了用 **Playwright**（Selenium 的替代方案）对 [https://openai.com](https://openai.com) 做全异步、无头浏览器爬取的方案。

开发者：[lakovicb](https://github.com/lakovicb)  
IDE：WingIDE Pro（通过 `nest_asyncio` 兼容 Jupyter）

---

## 功能

- 模拟类人交互（鼠标移动、滚动）
- 使用 OpenAI API 做 GPT 分析
- 可在 **JupyterLab** 中借助 `nest_asyncio` 运行
- Prometheus 指标，便于观测爬取过程
- 通过 `diskcache` 做智能内容缓存

---

## 如何运行

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

> 请确保 [已安装 Playwright 并下载浏览器](https://playwright.dev/python/docs/intro)

```bash
playwright install
```

### 2. 在 `.env` 中设置环境变量

```env
OPENAI_API_KEY=your_openai_key
BROWSER_PATH=/usr/bin/chromium-browser
```

如有需要，也可定义可选的代理/登录参数。
