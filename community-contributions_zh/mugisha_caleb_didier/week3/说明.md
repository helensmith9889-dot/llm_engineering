# 基尼亚卢旺达语-英语短语生成器

合成数据生成器，使用 Google Colab 上的开源法学硕士创建双语短语手册条目。

[![在 Colab 中打开](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1sStoMCqo7XTKAVB4JhxEtWhcYn0GEbt2?usp=sharing)

## 它的作用

- 生成 6 个实用类别的卢旺达语-英语短语对（问候、市场、旅行、食物、紧急情况、数字）
- 每个短语都包含语音发音指南和使用上下文
- 支持两种开源模型：Llama 3.2 3B 和 Qwen 2.5 3B（可通过 Gradio UI 切换）
- 将结果导出为可下载的 CSV

## 技能展示

- 从 HuggingFace 加载并运行开源模型
- 使用 BitsAndBytesConfig 进行 4 位量化
- 使用“apply_chat_template()”的聊天模板
- GPU 内存管理（一次加载一个模型）
- 具有交互式控件的 Gradio Blocks UI
- 结构化合成数据生成（从 LLM 输出进行 JSON 解析）

## 如何运行

1. 在 Google Colab 中打开笔记本（点击上面的徽章）
2. 选择 **T4 GPU** 运行时（运行时 > 更改运行时类型）
3. 将您的 HuggingFace 令牌添加到 Colab Secrets（密钥：`HF_TOKEN`）
4. 运行所有单元格
