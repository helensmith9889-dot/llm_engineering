# 笔记路由细则

## 目录

一律写在仓库根下的 `python学习笔记/`（与 `week1`/`week2` 同级）。

## 选哪个文件

1. **问的是 Python 语法本身**（dict、`.get`、f-string、import、推导式…）→ `基础语法.md`
2. **夹带「和 JS 比一下」** → 仍写 `基础语法.md`（同一小节里用对照表，不另开 js.md）
3. **问的是课程里的 LLM 概念**（system prompt、tool calling、RAG、embedding、微调、agent…）→ `llm.md`
4. **问的是 Gradio API / 组件** → `Gradio.md`

边界不清时：以「下次复习时会去哪翻」为准——语法翻 `基础语法.md`，模型能力翻 `llm.md`。

## 文件还不存在时

- `llm.md`：用一级标题 `# LLM 学习笔记` 创建，再写本小节。
- `基础语法.md` / `Gradio.md`：已存在则只追加。

## 与旧专题文件

历史上可能已有拆出去的篇（例如 `dict与f-string.md`）。  
**不要删除**它们；**新内容**按上表写入默认文件。若用户点名写进某个专题文件，服从用户。

## 追加位置

- 在目标文件**末尾**追加新 `##` 小节（或用户指定的锚点附近）。
- 若 `基础语法.md` 末尾已有「见 Gradio / 见 xxx」的引导行，新小节插在这些引导行**之前**。
