# Cursor Synth - 合成数据生成器

一套完整的合成数据生成工具包，提供两种部署方式：**本地/Colab notebook**（开源模型）与 **Python 应用**（云端推理）。

## 🚀 快速开始

### 方案 1：Python 应用（推荐）
**适合**：生产使用、云端推理、Hugging Face 模型

```bash
# 安装依赖
uv sync

# 配置环境
cp .env.example .env
# 在 .env 中填入 HF_API_KEY

# 运行 Gradio UI
uv run gradio_ui.py
```

### 方案 2：Jupyter Notebook
**适合**：实验、本地模型、Colab 部署

打开 `合成数据生成器_colab.ipynb`（原 `synthetic_data_generator_colab.ipynb`）：
- **Google Colab**（推荐，可免费用 GPU）
- **本地 Jupyter**（需本地模型环境）

## 📋 项目概览

### 🐍 Python 应用（`gradio_ui.py`）
**基于 Hugging Face Inference API 的云端推理**

**特点：** 轻量（无需本地下载模型）、启动快、始终可用最新模型、可扩展、易部署。

**支持模型：** SmolLM3-3B（默认）及 HF Inference API 上的其他模型。

### 📓 Jupyter Notebook
**本地模型推理，适合实验**

**特点：** 完全可控、无 API 费用（除算力外）、数据不离开本机、可定制、Colab 可用免费 GPU。

## 🎯 使用场景

**选 Python 应用：** 生产应用、需要快速可靠推理、不想管理模型、云部署、团队协作。

**选 Notebook：** 试验新模型、需要完全控制推理、处理敏感数据、学习模型内部、自定义微调。

## 🛠️ 技术架构

### Python 应用栈
```
Gradio UI → Generator → HFClient → Hugging Face Inference API
                ↓
         TemplateRegistry + Validator
```

### Notebook 栈
```
Jupyter → 本地模型加载 → Transformers → GPU/CPU 推理
                ↓
         自定义提示 + 校验
```

## 📊 数据模板

两种实现支持相同模板：用户画像、职位描述、产品规格、地址、以及自定义 schema/提示（含智能少样本示例）。

## 🔧 配置

```bash
HF_API_KEY=your_huggingface_token_here
PORT=7860  # 可选，默认 7860
```
