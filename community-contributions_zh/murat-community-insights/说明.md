# Murat 社区见解

一种基于人工智能的分析工具，可总结和分析 **LLM Engineering** 存储库的 **community-contributions** 目录中的项目。

该项目自动生成每个社区贡献的结构化摘要，并使用大型语言模型 (LLM) 提取生态系统级别的见解。

## 特点

- 总结每个贡献项目

- 提取所使用的可见技术
- 生成跨项目的生态系统见解

## 文件概述

**`summarize_contributions.py`**
扫描社区贡献文件夹并使用法学硕士生成摘要。

**`analyze_summaries.py`**
分析生成的摘要并提取生态系统级别的见解。

**`需求.txt`**
列出运行项目所需的 Python 依赖项。

**`结果/`**
存储生成的输出，例如项目摘要和分析报告。

---

## 它是如何工作的

### 第 1 步 — 生成项目摘要

该脚本扫描“community-contributions”目录并：

1.从项目文件夹中提取可读文本
2. 向 LLM 发送内容
3. 生成结构化摘要

运行：```bash
python summarize_contributions.py
```输出：```
results/community_contribution_summaries.json
```---

### 第 2 步 — 生成生态系统见解

第二个脚本分析所有生成的摘要以确定：

- 重复出现的项目主题
- 有趣或创新的项目
- 适合初学者的项目
- 常用技术

运行：```bash
python analyze_summaries.py
```输出：```
results/ecosystem_insights.md
```---

## 摘要输出示例

> **人工智能临床试验景观分析仪**
> 一种分析临床试验数据集的工具，可使用人工智能技术进行医疗保健分析来确定趋势和见解。

> **每日肯尼亚新闻摘要**
> 一个收集肯尼亚热门新闻文章并使用基于法学硕士的摘要生成简明摘要的系统。

## 注释

- 脚本自动跳过 `murat-community-insights` 文件夹以避免分析自身。
- `results/` 内生成的文件可能会根据存储库中存在的贡献而更改。
