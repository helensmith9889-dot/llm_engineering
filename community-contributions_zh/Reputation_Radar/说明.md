# ReputationRadar（口碑雷达）
> 实时品牌情报，输出人类可读洞察。

ReputationRadar 是一个 Streamlit 仪表盘：汇总 Reddit、Twitter/X 与 Trustpilot 讨论，用 OpenAI（或 VADER 回退）做情感分类，并产出可导出的高管摘要。项目包含模块化服务、缓存、带重试的爬虫、演示数据与 pytest 覆盖——可继续硬化后上线或内部部署。

## 功能亮点
- **自适应采集** – 可独立开关 Reddit、Twitter/X、Trustpilot；退避、缓存与礼貌抓取降低对平台的压力。
- **智能情感分析** – 批量 OpenAI 分类，提示含理由；无凭证时自动回退到 VADER。
- **可执行摘要** – 高管简报卡片（亮点、风险、语气、行动）+ 尊重边距与字体的 PDF 布局。
- **交互洞察** – Plotly 可视化、按来源筛选，以及精简的「代表性提及」链接列表，避免信息过载。
- **导出套件** – CSV、Excel（自动列宽）与精致 PDF 快照，便于交付干系人。
- **稳健基础** – 结构化日志、可复用 UI 组件、pytest、Dockerfile 与 Makefile，便于迭代。

## 架构概览
```
community-contributions/Reputation_Radar/
├── app.py                 # Streamlit 编排与布局
├── components/            # 侧边栏、仪表盘、摘要、加载器
├── services/              # Reddit/Twitter 客户端、Trustpilot 爬虫、LLM 封装、工具

├── assets/                # 占位图标/Logo
├── logs/                  # 流式日志输出
├── requirements.txt       # 运行依赖（含 PDF + Excel 写入）
├── Dockerfile             # 容器化部署配方
└── Makefile               # install/run/test 辅助目标
```
各服务返回归一化载荷，保证下游情感流水线确定。去重由中心模糊匹配处理，时间戳在分析前统一转为 UTC。

## 快速开始
1. **克隆并进入项目目录（`community-contributions/Reputation_Radar`）。**
2. **安装依赖并启动 Streamlit：**
   ```bash
   pip install -r requirements.txt && streamlit run app.py
   ```
   （可选虚拟环境。）
3. **填写侧边栏：** 品牌名、可选筛选、开关数据源、API 凭证（仅存于会话状态）。
4. **点击 “Run Analysis 🚀”** – 跟随状态指示：加载来源 → 情感处理 → 渲染摘要。

### 可选 Docker 运行
```bash
docker build -t reputation-radar .
docker run --rm -p 8501:8501 -e OPENAI_API_KEY=your_key reputation-radar
```

## 配置与凭证
应用从 `.env`、Streamlit secrets 或侧边栏直接输入读取。期望变量：

| 变量 | 用途 |
| --- | --- |
| `OPENAI_API_KEY` | 启用 OpenAI 情感 + 高管摘要（缺失则回退 VADER）。 |
| `REDDIT_CLIENT_ID` | Reddit API 的 PRAW client ID。 |
| `REDDIT_CLIENT_SECRET` | PRAW client secret。 |
| `REDDIT_USER_AGENT` | 描述性 User-Agent（如 `ReputationRadar/1.0 by you`）。 |
| `TWITTER_BEARER_TOKEN` | Twitter/X v2 最近搜索 bearer token。 |

凭证校验方式与 `week1/day1.ipynb` 指引一致——OpenAI 密钥输错会在分析开始前给出有用警告。

## 无 API 密钥时的用法
- Reddit/Twitter/Trustpilot 可独立开关；缺失凭证会温和警告而非硬失败。
- `samples/` 中的精选样例会为禁用数据源自动加载，演示模式下图表、导出与 PDF 仍可用。
- 无 `OPENAI_API_KEY` 时，LLM 层降为 VADER 情感打分，并跳过高管摘要。

## 导出与交付物
- **CSV** – 干净的 UTF-8 数据集，便于表格编辑。
- **Excel** – 自动列宽、格式化时间戳，可快速导入干系人工作簿。
- **PDF** – 专业排版高管摘要：项目列表、一致边距与自动换行摘录（基于 ReportLab Platypus）。

所有导出按需重新生成，不会在服务端持久化。

## 故障排查
- **OpenAI 密钥缺失/无效** – 关注侧边栏提示；应用会优雅回退，但不会生成高管摘要。
- **Twitter 401/403** – 确认 bearer token 权限范围，且项目已启用搜索访问。
- **限流（429）** – 内置 sleep 有帮助，但频繁请求仍可能需手动暂停。可收窄筛选或降低每源条数。
- **Trustpilot 拦截** – 遵守 robots.txt。若抓取被拒，改用官方 API 或提供合规 CSV 导入。
- **PDF 文字裁切** – 新布局已处理；若自定义模板，请确保列宽/表格样式仍在页边距内。

## 法律与合规
ReputationRadar 用于正当监测目的展示公开讨论。请始终遵守各平台服务条款、当地法规与隐私预期。避免超出必要时长存储第三方数据，切勿将 API 密钥提交到版本库——应用仅将密钥保存在 Streamlit 会话状态中。
