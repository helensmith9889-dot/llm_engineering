# 与 DriveSmart Insurance 就 Carllm 签订的合同

**合同日期：** 2025年3月20日
**合同编号：** CR-2025-E-0078
**当事方：**
- Insurellm, Inc.
- DriveSmart Insurance Corp.

---

## 条款

1. **覆盖范围：** Insurellm 同意向 DriveSmart Insurance 提供 Carllm 平台的企业级访问权限，包括白标能力、无限用户许可、专属基础设施，以及用于其多州汽车保险运营的完整 API 访问权限。

2. **期限：** 本协议自合同日期起有效期为36个月。

3. **付款：** DriveSmart Insurance 应按定制 Enterprise Tier 定价在第1–12个月每月支付18,000美元，第13–24个月每月支付19,500美元，第25–36个月每月支付21,000美元，合同期内合计702,000美元。

4. **保单量**：Enterprise Tier 支持无限保单。DriveSmart 目前在8个州拥有85,000份有效汽车保单。

5. **服务水平协议：** Insurellm 保证平台可用性达99.9%，按月计量；每低于目标0.1%给予当月8%贷记，最高不超过当月费用的40%。

6. **保密：** 双方同意就专有算法、驾驶人数据、定价模型及商业策略保持严格保密。

7. **数据安全：** Insurellm 维持 SOC 2 Type II 合规、年度渗透测试及全面网络安全保险覆盖。

---

## 续约

本协议包含双方90日续约通知期。DriveSmart 享有最惠客户定价保证，确保续约时具有竞争力的费率。合同可以12或24个月增量延期。

---

## 功能

DriveSmart Insurance 将获得完整的 Carllm Enterprise 套件：

1. **无限保单管理：** 全面支持 DriveSmart 的85,000+保单，并可扩展至500,000+保单。

2. **白标平台：** 完整定制：
   - 自定义域名（quote.drivesmartinsurance.com、portal.drivesmartinsurance.com）
   - 面向 iOS 与 Android 的品牌移动应用
   - 定制营销材料与报价工具
   - 联合品牌代理人门户

3. **高级人工智能风险评估：** 企业级风险分析：
   - 来自车载远程信息设备的实时驾驶人行为分析
   - 基于 VIN 解码与维护记录的车辆状况评估
   - 跨所有承保方的理赔历史分析（LexisNexis、CLUE）
   - 基于信用的保险评分
   - 含细粒度损失成本的地理风险建模
   - 多车与多驾驶人家庭优化
   - 商业汽车风险评估能力

4. **即时报价引擎：** 高性能报价：
   - 3秒内生成报价
   - 跨50+评级因子的实时费率优化
   - 含市场定位的竞争情报
   - 基于需求与承保能力的动态定价
   - 多产品捆绑折扣（汽车+房屋）
   - 定价策略 A/B 测试能力

5. **可定制保障计划：** 灵活产品配置：
   - 州特定保障选项（全部8个经营州）
   - 基于使用量的保险（UBI）计划
   - 按英里付费选项
   - 网约车与配送驾驶人保障
   - 经典车与收藏车计划
   - SR-22 与高风险驾驶人计划

6. **高级欺诈检测：** 全面欺诈防范：
   - 投保欺诈检测（身份核验、地址验证）
   - 含模式识别的理赔欺诈分析
   - 代理人欺诈监控
   - 伪造事故检测
   - 欺诈团伙社会网络分析
   - 与 NICB 及 SIU 数据库集成

7. **客户洞察仪表板：** 深度分析：
   - 实时保单指标与 KPI
   - 留存与流失分析
   - 按细分的赔付率跟踪
   - 代理人绩效分析
   - 营销活动投资回报测量
   - 客户终身价值预测

8. **远程信息处理集成：** 完整远程信息处理平台：
   - 设备无关集成（OBD-II 加密狗、智能手机应用、嵌入式）
   - 实时驾驶人行为评分
   - 行程级数据分析（急刹、加速、转弯、超速）
   - 低里程折扣的里程核验
   - 事故检测与紧急响应
   - 驾驶人辅导与反馈计划
   - 游戏化与安全驾驶奖励

9. **完整 API 访问：** 无限 API 调用：
   - 与 DriveSmart 核心系统集成
   - 代理人管理系统连接
   - 第三方数据提供方（LexisNexis、Verisk、Experian）
   - DMV 与 MVR 集成
   - 支付处理系统
   - 文档管理平台
   - 营销自动化工具

10. **多州运营：** 全面州支持：
    - 州特定表格与批单
    - 监管合规监控
    - 费率备案管理
    - 多州代理人执照跟踪
    - 必要时的剩余市场支持
