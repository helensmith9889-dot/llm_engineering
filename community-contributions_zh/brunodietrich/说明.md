# Bruno 的第 1 周技术导师

本贡献是第 1 周练习的个性化版本。

它用以下技术搭建了一个小型技术导师：

- OpenAI `gpt-4o-mini`（流式输出）
- 本地 Ollama `llama3.2`
- 个性化导师提示词
- 一小段多示例（multi-shot）以引导回答风格

导师风格偏友好、简洁。在能说得更清楚时，可结合 Godot/游戏开发、PHP 或 DevOps 的实际例子。

运行 notebook 之前：

```bash
ollama pull llama3.2
ollama serve
```

并确保 `.env` 中已配置 `OPENAI_API_KEY`。
