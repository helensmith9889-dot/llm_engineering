# 团队中的心理安全（Psychological Safety）

**快速摘要（2–4 句）：**  
> 心理安全指团队成员敢于发言、提问、承认错误，而不必担心被嘲笑或惩罚。据 Google 的 Project Aristotle，它是高绩效团队的核心因素之一。  

**细微差别 / 注意点：**  
- 不等于“舒适区”；团队仍需要问责。  
- 文化背景会影响对“安全”的感知。  
- 建立心理安全需要一贯的领导行为。  

**核心概念：**  
- **信任：** 相信他人不会羞辱或惩罚自己。  
- **学习氛围：** 对错误与提问保持开放。  
- **包容型领导：** 邀请所有人参与。  

**直观例子 / 演示：**  
> 在心理安全的团队里，初级工程师可以指出 CTO 设计中的 bug，而不必害怕被打击报复。  

**何时有用 / 局限：**  
- 有利于创新、发现错误、建设学习文化。  
- 局限：只强调安全而缺少问责，可能降低绩效。  

**简洁学习路径（4–7 步）：**  
1. 阅读 Amy Edmondson 的 *The Fearless Organization*。  
2. 观看 Google Project Aristotle 案例（约 1 小时）。  
3. 在回顾会议中做开放式复盘与安全签到。  
4. 做小实验（匿名反馈、领导展示脆弱性）。  

**练习（2–4，含难度）：**  
1. [简单] 回忆一次会议上你没有发言的经历。  
2. [中等] 在团队中做一次“安全检查”调研。  

**参考与引用**  
1. Edmondson A. *The Fearless Organization* (2018).  
2. Google re:Work — Project Aristotle 发现。
