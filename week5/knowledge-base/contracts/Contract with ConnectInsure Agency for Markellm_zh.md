# 与 ConnectInsure Agency 就 Markellm 签订的合同

**合同日期：** 2025年2月28日
**合同编号：** MK-2025-0056

---

## 条款

1. **当事方**：本合同由 Insurellm, Inc.（“提供方”）与 ConnectInsure Agency（“客户”）订立。

2. **服务起始**：服务将于2025年3月1日开始。

3. **合同期限**：本协议自起始日起有效期为18个月，于2026年8月31日届满。

4. **费用结构**：ConnectInsure Agency 同意采用混合定价模式：
   - 基础上市费：每月199美元，用于 Markellm 平台精选展示位
   - 按绩效计费：通过 Markellm 生成的每条合格线索25美元
   - 高级分析套餐（可选）：每月99美元，用于增强数据洞察与报告

5. **线索量预期**：根据 ConnectInsure 的概况，Markellm 预计每月产生80–120条合格线索，估计月费用为2,199–3,199美元。

6. **付款条款**：
   - 月度上市费于每月1日到期
   - 按绩效费用于每月5日就上月活动开具发票
   - 发票开具后15日内通过 ACH 或信用卡支付

7. **线索质量标准**：合格线索须满足以下标准：
   - 有效联系信息（经核实的电话与电子邮件）
   - 主动保险购物意向（7日内请求报价）
   - 地理覆盖范围位于 ConnectInsure 经营区域内
   - 产品与 ConnectInsure 产品线匹配

8. **争议解决**：线索质量争议须在5个工作日内连同证明文件提交。Insurellm 将对经核实的低质量线索予以贷记。

## 续约

1. **自动续约**：本协议自动续约连续6个月期限，除非任何一方在到期前至少30日提供书面不续约通知。

2. **费用调整**：上市费与绩效费用可每年调整，并提前60日书面通知。历史平均：每年调整5–8%。

## 功能

1. **人工智能驱动匹配**：ConnectInsure Agency 将受益于 Markellm 的先进匹配能力：
   - 使用机器学习算法进行消费者需求分析
   - 跨汽车、房屋、人寿、健康保险的产品与需求匹配
   - 地理与专业领域匹配
   - 价格区间与保障偏好对齐
   - 消费者人口统计特征与 ConnectInsure 优势客群匹配

2. **精选上市**：高级市场展示位包括：
   - 增强代理机构资料，含徽标、照片、客户评价
   - 专业化徽章（例如“高风险车险专家”“多保单专家”）
   - 搜索结果优先定位
   - 在相关消费者匹配中精选展示
   - 代理机构上市内最多10个代理人资料

3. **实时报价集成**：技术支持：
   - 与 ConnectInsure 报价系统的 API 集成
   - 向消费者实时展示费率
   - 竞争定位洞察
   - 报价放弃挽回活动

4. **线索管理门户**：综合工具用于：
   - 实时线索通知（短信、电子邮件、推送）
   - 按专业领域将线索路由至特定代理人
   - 跟进任务管理与 CRM 集成
   - 线索状态跟踪（已联系、已报价、已成交、已拒绝）
   - 按代理人与产品线的绩效分析

5. **数据洞察**：分析仪表板提供：
   - 线索量趋势与预测
   - 转化率分析
   - 获客成本指标
   - 竞争基准对比（匿名化）
   - 消费者行为洞察
   - 产品组合建议

6. **消费者评价**：声誉管理：
   - 消费者评分与评价收集
   - 评价回复管理
   - 代理机构资料上的评价展示
   - 负面评价调解支持

7. **营销支持**：平台提供的营销：
   - 联合品牌营销材料
   - 面向温线索的电子邮件培育活动
   - 社交媒体内容建议
   - 季节性活动参与
   - 推荐计划集成

## 支持

1. **技术支持**：ConnectInsure Agency 将获得：
   - 周一至周五东部时间上午8时至下午6时的电子邮件与电话支持
   - 响应时间：标准咨询24小时
   - 在线帮助中心与常见问题
   - 平台功能视频教程

2. **入职实施**：实施包括：
   - 为期2周的入职流程
   - 最多5名代理机构员工的平台培训（合计3小时）
   - 资料优化咨询
   - 报价集成设置（如适用）
   - CRM 集成协助

3. **客户管理**：
   - 指定客户经理，每月跟进
   - 季度绩效评审
   - 线索质量监控与优化
   - 竞争定位建议
   - 分享顶尖表现代理机构的最佳实践

4. **平台更新**：
   - 定期功能增强
   - 移动应用更新
   - 消费者体验改进
   - 新产品线增加
   - 重大变更提前通知（至少14日）

5. **营销协助**：
   - 季度营销策略咨询
   - 活动绩效分析
   - 消费者趋势报告
   - 联合营销机会识别
