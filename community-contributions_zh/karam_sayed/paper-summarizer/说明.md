# paperSuMMARiZER（论文摘要器）

###### 基于本地 Ollama 的研究论文摘要工具。粘贴任意研究论文 URL，即可得到干净、结构化的 Markdown 摘要，包含标题、作者、方法、技术、参考文献、研究空白等字段。

---

## 工作原理

1. 将研究论文 URL 交给 [Jina AI Reader](https://jina.ai/reader/) 抓取完整页面内容。
2. 把内容发送给通过 Ollama 运行的本地 `llama3.2:3b` 模型。
3. 模型提取关键章节并格式化为清晰的 Markdown。

---

## 安装指南

### 先决条件

- Python 3.10+
- 已安装并在本地运行 [Ollama](https://ollama.com)
- 已安装并可用 [uv](https://docs.astral.sh/uv/)
- [Jina AI](https://jina.ai) API Key（有免费额度）

---

### 步骤 1 — 克隆仓库

```bash
git clone https://github.com/ed-donner/llm_engineering.git
cd llm_engineering
```

### 步骤 2 — 配置 API Key

在项目根目录创建 `.env` 文件：

```
JINA_API_KEY=your_jina_api_key_here
```

> **说明：** Jina AI Reader API Key 用于抓取论文页面。可在 [https://jina.ai](https://jina.ai) 免费申请。

### 步骤 3 — 打开项目

用你喜欢的编辑器（如 VS Code 或 Cursor）打开 `llm_engineering` 文件夹。  
笔记本路径：

```
community-contribution/karam_sayed/paper-summarizer/paperSUMMARiZER.ipynb
```

在笔记本中设置目标论文 URL：

```python
paper_url = 'https://your-research-paper-url-here'
```

### 步骤 4 — 选择内核

确保已用 uv 安装所需依赖。然后选择 Jupyter 内核，建议 Python 3.12.x。

### 步骤 5 — 运行全部单元格

```
运行 paperSUMMARizer.ipynb 中的全部单元格
```
