## 项目概述

我构建了一套完整的技术问答系统，功能超出基础要求。系统可接收技术问题，并通过多个 AI 提供商给出详尽、含代码的回答。

## 核心实现

### 命令行界面
- 构建带参数解析的专业 CLI
- 增加校验与错误处理
- 支持多种执行方式（直接命令、模块语法、批处理文件）
- 实现帮助系统与用法示例

### 多提供商架构
集成了三个 AI 提供商，方便用户灵活选择：

**OpenAI 集成：**
- 完整 API 集成与正确鉴权
- 可配置模型选择
- 超时与重试逻辑

**Ollama 集成：**
- 支持本地模型以保护隐私
- 为零成本选项
- 自动检测可用性

**OpenRouter 集成：**
- 经济地将请求路由到多种模型
- 可访问最新 AI 模型
- 正确的请求头与鉴权

### 智能提供商选择
构建了自动检测系统，可：
- 检查可用的 API 密钥
- 测试提供商可用性
- 在提供商不可用时优雅回退
- 优先选择更经济的方案
