# LLM 导师

一个使用大语言模型为学生问题提供结构化教学回答的智能辅导系统。系统采用两阶段方法：先用元提示（meta-prompt）结构化用户问题，再用系统提示与少样本示例生成完整教学回答。

## 功能

- **两阶段处理**：先用元提示结构化问题，再结合教学上下文生成回答
- **多模型支持**：同时支持 GPT-4o-mini 与 Llama 3.2
- **少样本学习**：用示例对话提升回答质量
- **流式输出**：实时生成回答，体验更好
- **稳健错误处理**：覆盖文件操作与 API 调用
- **可配置提示**：系统提示与元提示易于修改
- **交互式命令行**：简洁友好的 CLI 界面

## 安装

1. 克隆仓库：
```bash
git clone <repository-url>
cd LLM_tutor
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

或使用 uv（推荐）：
```bash
uv add openai python-dotenv frontmatter
```

3. 配置环境变量：
在项目根目录创建 `.env`，写入 OpenAI API 密钥：
```
OPENAI_API_KEY=your_api_key_here
```

## 用法

### 命令行界面

从命令行运行交互式导师：

```bash
python llm_tutor.py
```

程序会：
1. 让你在 GPT-4o-mini 与 Llama 3.2 之间选择
2. 提示输入问题
3. 用元提示结构化你的问题
4. 以流式输出生成教学回答
5. 允许在同一会话中追问

### 编程方式调用

```python
from llm_tutor import LLMTutor, get_client

# 初始化导师
client = get_client("openai")  # 或 "ollama"
tutor = LLMTutor('gpt-4o-mini', client)

# 获取结构化后的问题
question = "What is machine learning?"
structured_question = tutor.get_structured_question(question)

# 获取教学回答
response = tutor.get_response(structured_question, stream=True)
print(response)
```

## 配置

### 提示词

- **系统提示**（`prompts/system_prompt.txt`）：定义教学人设与回答风格
- **元提示**（`prompts/meta_prompt.txt`）：用于结构化与澄清用户问题
- **少样本示例**（`prompts/few_shots/*.md`）：带 frontmatter（含用户问题）的示例对话

### 少样本示例格式

在 `prompts/few_shots/` 中创建如下结构的 markdown：

```markdown
---
user: "What is the difference between supervised and unsupervised learning?"
---

监督学习使用带标签的训练数据学习从输入到输出的映射，而无监督学习在无显式标签的情况下发现数据中的模式……
```

## API 要求

- **OpenAI API Key**：访问 GPT-4o-mini 所需
- **Ollama**：本地运行 Llama 3.2 所需

## 快速开始

1. **安装依赖**
2. **配置 API 密钥**（`.env`）
3. **运行**：`python llm_tutor.py`
4. **按提示操作**：选模型 → 提问 → 可继续追问

## 错误处理

应用对以下情况有较完整处理：缺失/无效 API 密钥、文件未找到、权限错误、Unicode 解码错误、API 请求失败、键盘中断。

## 故障排除

1. **API Key 错误**：确认 `.env` 中密钥正确
2. **文件未找到**：检查提示文件是否在正确目录
3. **权限错误**：确保对所有文件有读权限
4. **模型不可用**：确认所选模型在当前环境可用
